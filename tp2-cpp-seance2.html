02

Les boucles

Trois boucles, trois usages typiques.
BoucleQuand l'utiliser
forLe nombre de répétitions est connu à l'avance
whileOn répète tant qu'une condition reste vraie, sans savoir combien de fois
do-whileComme while, mais le corps s'exécute au moins une fois
// for
for (int i = 0; i < 10; i++) {
    std::cout << i << " ";
}

// while
int n = 10;
while (n > 0) {
    std::cout << n << " ";
    n--;
}

// do-while
int choix;
do {
    std::cout << "Entrez 0 pour quitter : ";
    std::cin >> choix;
} while (choix != 0);
Piège fréquent : une boucle while dont la condition ne devient jamais fausse tourne indéfiniment (boucle infinie) — toujours vérifier que quelque chose change à l'intérieur de la boucle.
03

Les tableaux

Un tableau statique stocke plusieurs valeurs de même type, à taille fixe, indexées à partir de 0 :

int notes[5] = {12, 15, 9, 18, 14};
std::cout << notes[0]; // 12, premier élément
std::cout << notes[4]; // 14, dernier élément

Parcourir un tableau avec une boucle for :

int taille = 5;
int somme = 0;
for (int i = 0; i < taille; i++) {
    somme += notes[i];
}
Piège fréquent : accéder à notes[5] dans un tableau de taille 5 est un accès hors limites — C++ ne le détecte pas automatiquement et le comportement est indéfini.
04

Les fonctions

Une fonction regroupe des instructions réutilisables sous un nom, avec des paramètres en entrée et une valeur de retour :

int carre(int x) {
    return x * x;
}

int main() {
    std::cout << carre(5); // 25
}

Par défaut, les paramètres sont passés par valeur : la fonction reçoit une copie, les modifications à l'intérieur n'affectent pas la variable d'origine. Pour modifier réellement la variable appelante, on passe par référence avec & :

void doubler(int& x) {
    x = x * 2;
}

int main() {
    int valeur = 5;
    doubler(valeur);
    std::cout << valeur; // 10
}
À retenir : void signifie que la fonction ne retourne aucune valeur.

Exercices pratiques

Écrire son propre code avant de dérouler la solution. Les exercices 4 à 6 réutilisent les notions des séances précédentes.
Ex. 1

Table de multiplication

échauffement

Demander un nombre entier à l'utilisateur et afficher sa table de multiplication de 1 à 10, en utilisant une boucle for.

Voir la solution 
#include <iostream>

int main() {
    int n;
    std::cout << "Nombre : ";
    std::cin >> n;

    for (int i = 1; i <= 10; i++) {
        std::cout << n << " x " << i << " = " << (n * i) << std::endl;
    }

    return 0;
}
Ex. 2

Somme et moyenne d'un tableau

facile

Déclarer un tableau de 6 notes (valeurs de votre choix), calculer et afficher leur somme et leur moyenne.

Voir la solution 
#include <iostream>

int main() {
    double notes[6] = {12, 15, 9, 18, 14, 11};
    double somme = 0;

    for (int i = 0; i < 6; i++) {
        somme += notes[i];
    }

    double moyenne = somme / 6;
    std::cout << "Somme : " << somme << std::endl;
    std::cout << "Moyenne : " << moyenne << std::endl;

    return 0;
}
Ex. 3

Trouver le maximum

facile

Écrire une fonction int maximum(int tab[], int taille) qui retourne la plus grande valeur d'un tableau, puis l'utiliser dans main.

Voir la solution 
#include <iostream>

int maximum(int tab[], int taille) {
    int max = tab[0];
    for (int i = 1; i < taille; i++) {
        if (tab[i] > max) {
            max = tab[i];
        }
    }
    return max;
}

int main() {
    int valeurs[5] = {3, 17, 8, 22, 14};
    std::cout << "Maximum : " << maximum(valeurs, 5) << std::endl;

    return 0;
}
Ex. 4

Nombre premier

intermédiaire

Écrire une fonction bool estPremier(int n) qui retourne true si n est premier, en testant les diviseurs de 2 à n - 1 avec une boucle for.

Voir la solution 
#include <iostream>

bool estPremier(int n) {
    if (n < 2) {
        return false;
    }
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int n;
    std::cout << "Entrez un entier : ";
    std::cin >> n;

    if (estPremier(n)) {
        std::cout << n << " est premier." << std::endl;
    } else {
        std::cout << n << " n'est pas premier." << std::endl;
    }

    return 0;
}

Optimisation possible : on peut arrêter la boucle dès que i * i > n, mais la version simple ci-dessus suffit à ce stade.

Ex. 5

Échanger deux valeurs

intermédiaire

Écrire une fonction void echanger(int& a, int& b) qui échange les valeurs de deux entiers en utilisant le passage par référence. Vérifier dans main que les variables d'origine sont bien modifiées.

Voir la solution 
#include <iostream>

void echanger(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3, y = 8;
    std::cout << "Avant : x=" << x << " y=" << y << std::endl;

    echanger(x, y);

    std::cout << "Après : x=" << x << " y=" << y << std::endl;

    return 0;
}

Sans le & dans les paramètres, la fonction échangerait seulement des copies locales et x/y resteraient inchangés dans main.

Ex. 6

Inverser un tableau

défi

Écrire une fonction void inverser(int tab[], int taille) qui inverse l'ordre des éléments d'un tableau en place (sans créer de nouveau tableau), puis afficher le tableau avant et après dans main.

Voir la solution 
#include <iostream>

void inverser(int tab[], int taille) {
    for (int i = 0; i < taille / 2; i++) {
        int temp = tab[i];
        tab[i] = tab[taille - 1 - i];
        tab[taille - 1 - i] = temp;
    }
}

void afficher(int tab[], int taille) {
    for (int i = 0; i < taille; i++) {
        std::cout << tab[i] << " ";
    }
    std::cout << std::endl;
}

int main() {
    int valeurs[5] = {1, 2, 3, 4, 5};

    std::cout << "Avant : ";
    afficher(valeurs, 5);

    inverser(valeurs, 5);

    std::cout << "Après : ";
    afficher(valeurs, 5);

    return 0;
}

Un tableau passé en paramètre agit déjà comme une référence en C++ : inverser modifie directement le tableau du main, sans besoin de &.
