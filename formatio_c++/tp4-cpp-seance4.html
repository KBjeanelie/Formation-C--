02

Héritage

Une classe fille hérite des attributs et méthodes d'une classe mère, et peut ajouter ou redéfinir des comportements.
class Employe {
protected:
    std::string nom;
    double salaireBase;

public:
    Employe(std::string n, double s) {
        nom = n;
        salaireBase = s;
    }

    double salaire() {
        return salaireBase;
    }
};

class Manager : public Employe {
private:
    double prime;

public:
    Manager(std::string n, double s, double p) : Employe(n, s) {
        prime = p;
    }

    double salaire() {
        return salaireBase + prime;
    }
};

Manager hérite de Employe : il possède déjà nom et salaireBase, et son constructeur appelle celui de la classe mère avec : Employe(n, s). La méthode salaire() est redéfinie pour ajouter la prime.

Mot-cléRôle
protectedAccessible dans la classe et ses classes filles, mais pas depuis l'extérieur
: public EmployeManager hérite publiquement d'Employe
03

Polymorphisme

Avec virtual sur la classe mère et override sur la classe fille, on peut manipuler différents types d'objets à travers un pointeur ou une référence de type mère, et chaque objet exécute sa propre version de la méthode :

class Animal {
public:
    virtual void parler() { std::cout << "..." << std::endl; }
};

class Chien : public Animal {
public:
    void parler() override { std::cout << "Wouf" << std::endl; }
};

class Chat : public Animal {
public:
    void parler() override { std::cout << "Miaou" << std::endl; }
};
À retenir : sans virtual, un pointeur ou une référence de type Animal appellerait toujours la version Animal::parler(), même pour un objet Chat.
04

La bibliothèque standard : std::vector

Contrairement à un tableau classique, un std::vector peut grandir dynamiquement (nécessite #include <vector>) :

#include <vector>

std::vector<int> notes;
notes.push_back(12);
notes.push_back(15);
notes.push_back(9);

for (int i = 0; i < notes.size(); i++) {
    std::cout << notes[i] << " ";
}

// ou, plus idiomatique :
for (int n : notes) {
    std::cout << n << " ";
}
MéthodeRôle
push_back(x)Ajoute x à la fin
size()Nombre d'éléments actuels
[i]Accès à l'élément d'indice i
empty()Vrai si le vecteur ne contient aucun élément

Un vecteur peut aussi contenir des objets d'une classe, comme std::vector<Employe>.

Exercices pratiques

Ces exercices préparent directement le mini-projet ci-dessous.
Ex. 1

Formes géométriques

facile

Créer une classe mère Forme avec une méthode virtual double aire() retournant 0, puis deux classes filles Carre et Cercle (constante M_PI ou 3.14159) qui redéfinissent aire().

Voir la solution 
#include <iostream>

class Forme {
public:
    virtual double aire() { return 0; }
};

class Carre : public Forme {
private:
    double cote;
public:
    Carre(double c) { cote = c; }
    double aire() override { return cote * cote; }
};

class Cercle : public Forme {
private:
    double rayon;
public:
    Cercle(double r) { rayon = r; }
    double aire() override { return 3.14159 * rayon * rayon; }
};

int main() {
    Carre c(4);
    Cercle ce(3);
    std::cout << "Aire carré : " << c.aire() << std::endl;
    std::cout << "Aire cercle : " << ce.aire() << std::endl;

    return 0;
}
Ex. 2

Vecteur de notes

facile

Lire un nombre inconnu de notes saisies par l'utilisateur (l'utilisateur tape -1 pour arrêter), les stocker dans un std::vector<double>, puis afficher leur moyenne.

Voir la solution 
#include <iostream>
#include <vector>

int main() {
    std::vector<double> notes;
    double saisie;

    std::cout << "Entrez des notes (-1 pour arrêter) : " << std::endl;
    while (true) {
        std::cin >> saisie;
        if (saisie == -1) {
            break;
        }
        notes.push_back(saisie);
    }

    if (notes.empty()) {
        std::cout << "Aucune note saisie." << std::endl;
        return 0;
    }

    double somme = 0;
    for (double n : notes) {
        somme += n;
    }

    std::cout << "Moyenne : " << (somme / notes.size()) << std::endl;

    return 0;
}
Ex. 3

Hiérarchie Employe / Manager

intermédiaire

Reprendre les classes Employe et Manager de la section héritage, les compléter si besoin, créer un std::vector<Employe>... puis constater la limite : un vecteur d'Employe ne peut pas stocker directement des Manager sans perdre leurs spécificités (voir la note ci-dessous).

Voir la solution 
#include <iostream>
#include <vector>

class Employe {
protected:
    std::string nom;
    double salaireBase;
public:
    Employe(std::string n, double s) { nom = n; salaireBase = s; }
    double salaire() { return salaireBase; }
    std::string getNom() { return nom; }
};

class Manager : public Employe {
private:
    double prime;
public:
    Manager(std::string n, double s, double p) : Employe(n, s) { prime = p; }
    double salaire() { return salaireBase + prime; }
};

int main() {
    Employe e1("Nadia", 300000);
    Manager m1("Bruno", 400000, 100000);

    std::cout << e1.getNom() << " : " << e1.salaire() << " FCFA" << std::endl;
    std::cout << m1.getNom() << " : " << m1.salaire() << " FCFA" << std::endl;

    return 0;
}

Le mini-projet ci-dessous montre comment gérer proprement un groupe d'employés de types différents, en gardant chaque type dans son propre vecteur plutôt qu'en les mélangeant.

Mini-projet

À réaliser en autonomie ou en binôme, en s'appuyant sur tout ce qui a été vu depuis la séance 1.

Gestion d'une petite bibliothèque

Cahier des charges à implémenter, puis solution complète repliable ci-dessous.

  • Une classe Livre avec titre, auteur et disponible (bool), un constructeur, et des méthodes emprunter() et rendre() qui changent disponible.
  • Une classe Bibliotheque qui contient un std::vector<Livre>, avec des méthodes ajouterLivre(Livre l), afficherCatalogue(), et emprunterLivre(std::string titre) qui recherche le livre par titre et l'emprunte s'il est disponible.
  • Un main() qui crée une bibliothèque, y ajoute au moins 4 livres, affiche le catalogue, emprunte deux livres (dont un déjà emprunté, pour tester le refus), puis réaffiche le catalogue.
Voir la solution complète 
#include <iostream>
#include <vector>
#include <string>

class Livre {
private:
    std::string titre;
    std::string auteur;
    bool disponible;

public:
    Livre(std::string t, std::string a) {
        titre = t;
        auteur = a;
        disponible = true;
    }

    std::string getTitre() { return titre; }
    bool estDisponible() { return disponible; }

    bool emprunter() {
        if (disponible) {
            disponible = false;
            return true;
        }
        return false;
    }

    void rendre() {
        disponible = true;
    }

    void afficher() {
        std::cout << "- " << titre << " (" << auteur << ") — "
                  << (disponible ? "disponible" : "emprunté") << std::endl;
    }
};

class Bibliotheque {
private:
    std::vector<Livre> livres;

public:
    void ajouterLivre(Livre l) {
        livres.push_back(l);
    }

    void afficherCatalogue() {
        std::cout << "--- Catalogue ---" << std::endl;
        for (int i = 0; i < livres.size(); i++) {
            livres[i].afficher();
        }
    }

    void emprunterLivre(std::string titreRecherche) {
        for (int i = 0; i < livres.size(); i++) {
            if (livres[i].getTitre() == titreRecherche) {
                if (livres[i].emprunter()) {
                    std::cout << "Emprunté : " << titreRecherche << std::endl;
                } else {
                    std::cout << "Indisponible : " << titreRecherche << std::endl;
                }
                return;
            }
        }
        std::cout << "Livre introuvable : " << titreRecherche << std::endl;
    }
};

int main() {
    Bibliotheque biblio;
    biblio.ajouterLivre(Livre("Une si longue lettre", "Mariama Bâ"));
    biblio.ajouterLivre(Livre("L'enfant noir", "Camara Laye"));
    biblio.ajouterLivre(Livre("Les soleils des indépendances", "Ahmadou Kourouma"));
    biblio.ajouterLivre(Livre("Le pleurer-rire", "Henri Lopes"));

    biblio.afficherCatalogue();

    biblio.emprunterLivre("L'enfant noir");
    biblio.emprunterLivre("L'enfant noir"); // déjà emprunté

    std::cout << std::endl;
    biblio.afficherCatalogue();

    return 0;
}

Pistes d'extension pour aller plus loin : ajouter une méthode rendreLivre(titre), une classe Adherent qui emprunte les livres, ou une hiérarchie Livre / BandeDessinee avec héritage.
