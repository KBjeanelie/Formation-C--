03

Variables et types

Une variable est une case mémoire nommée et typée. Le type fixe à l'avance ce que la variable peut contenir et combien de place elle occupe.
TypeContenuExemple
intNombre entierint age = 20;
doubleNombre à virgule (précis)double prix = 12.5;
charUn seul caractèrechar lettre = 'A';
boolVrai ou fauxbool actif = true;
std::stringChaîne de caractèresstd::string nom = "Alice";

Une variable déclarée const ne peut plus changer de valeur après son initialisation :

const double TAUX_TVA = 0.18;
Piège fréquent : std::string nécessite #include <string>, et une division entre deux int comme 7 / 2 donne 3, pas 3.5.

05

Entrées / sorties

std::cout affiche, std::cin lit une entrée clavier :

int age;
std::cout << "Quel âge as-tu ? ";
std::cin >> age;
std::cout << "Tu as " << age << " ans." << std::endl;

Pour lire une chaîne contenant des espaces, préférer std::getline(std::cin, variable) plutôt que cin >>.

06

Structures conditionnelles

if (note >= 10) {
    std::cout << "Admis";
} else if (note >= 8) {
    std::cout << "Rattrapage";
} else {
    std::cout << "Refusé";
}

switch est adapté quand une seule variable est comparée à plusieurs valeurs fixes ; ne pas oublier break; après chaque case :

switch (jour) {
    case 1: std::cout << "Lundi"; break;
    case 2: std::cout << "Mardi"; break;
    default: std::cout << "Autre jour";
}

Exercices pratiques

Ex. 1

Carte d'identité

échauffement

Déclarer des variables pour un nom (string), un âge (int) et une taille en mètres (double). Les initialiser puis les afficher sur une seule ligne, séparées par des virgules.

Voir la solution 
#include <iostream>
#include <string>

int main() {
    std::string nom = "Aïssa";
    int age = 22;
    double taille = 1.68;

    std::cout << nom << ", " << age << " ans, " << taille << " m" << std::endl;

    return 0;
}
Ex. 2

Calculatrice de rectangle

facile

Demander à l'utilisateur la largeur et la hauteur d'un rectangle (deux double), puis afficher son aire et son périmètre.

Voir la solution 
#include <iostream>

int main() {
    double largeur, hauteur;

    std::cout << "Largeur : ";
    std::cin >> largeur;
    std::cout << "Hauteur : ";
    std::cin >> hauteur;

    double aire = largeur * hauteur;
    double perimetre = 2 * (largeur + hauteur);

    std::cout << "Aire : " << aire << std::endl;
    std::cout << "Périmètre : " << perimetre << std::endl;

    return 0;
}
Ex. 3

Pair ou impair

facile

Lire un entier saisi par l'utilisateur et afficher s'il est pair ou impair, en utilisant l'opérateur %.

Voir la solution 
#include <iostream>

int main() {
    int n;
    std::cout << "Entrez un entier : ";
    std::cin >> n;

    if (n % 2 == 0) {
        std::cout << n << " est pair." << std::endl;
    } else {
        std::cout << n << " est impair." << std::endl;
    }

    return 0;
}

Astuce : cela fonctionne aussi pour les nombres négatifs, car -4 % 2 vaut 0.

Ex. 4

Correcteur de notes

intermédiaire

Lire une note sur 20 et afficher une mention selon le barème suivant : ≥ 16 "Très bien", ≥ 14 "Bien", ≥ 12 "Assez bien", ≥ 10 "Passable", en dessous "Insuffisant".

Voir la solution 
#include <iostream>

int main() {
    double note;
    std::cout << "Note sur 20 : ";
    std::cin >> note;

    if (note >= 16) {
        std::cout << "Très bien" << std::endl;
    } else if (note >= 14) {
        std::cout << "Bien" << std::endl;
    } else if (note >= 12) {
        std::cout << "Assez bien" << std::endl;
    } else if (note >= 10) {
        std::cout << "Passable" << std::endl;
    } else {
        std::cout << "Insuffisant" << std::endl;
    }

    return 0;
}

Attention à l'ordre des conditions : elles doivent aller de la plus haute à la plus basse pour que la première condition vraie soit bien la bonne mention.

Ex. 5

Convertisseur de devises

intermédiaire

Demander un montant en FCFA et convertir en euros avec un taux fixe const double TAUX = 655.96; (1 EUR = 655,96 FCFA). Afficher le résultat avec deux décimales grâce à std::fixed et std::setprecision(2) (nécessite #include <iomanip>).

Voir la solution 
#include <iostream>
#include <iomanip>

int main() {
    const double TAUX = 655.96;
    double montantFCFA;

    std::cout << "Montant en FCFA : ";
    std::cin >> montantFCFA;

    double montantEUR = montantFCFA / TAUX;

    std::cout << std::fixed << std::setprecision(2);
    std::cout << montantFCFA << " FCFA = " << montantEUR << " EUR" << std::endl;

    return 0;
}
Ex. 6

Menu du jour

défi

Demander un numéro de jour (1 à 7) et afficher le nom du jour correspondant avec un switch. Si le numéro n'est pas entre 1 et 7, afficher "Jour invalide" via le default.

Voir la solution 
#include <iostream>

int main() {
    int jour;
    std::cout << "Numéro du jour (1-7) : ";
    std::cin >> jour;

    switch (jour) {
        case 1: std::cout << "Lundi"; break;
        case 2: std::cout << "Mardi"; break;
        case 3: std::cout << "Mercredi"; break;
        case 4: std::cout << "Jeudi"; break;
        case 5: std::cout << "Vendredi"; break;
        case 6: std::cout << "Samedi"; break;
        case 7: std::cout << "Dimanche"; break;
        default: std::cout << "Jour invalide";
    }
    std::cout << std::endl;

    return 0;
}
