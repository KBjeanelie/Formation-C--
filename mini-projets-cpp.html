01

Gestionnaire de Contacts

Le cas réel : Une entreprise a besoin d'un mini-outil en ligne de commande pour enregistrer rapidement les coordonnées de ses prospects sur un salon. Le programme doit permettre d'ajouter, lister et rechercher des contacts en mémoire.

Objectifs Techniques

  • Utilisation d'une struct ou d'une class.
  • Stockage dynamique avec std::vector.
  • Boucle principale d'interface utilisateur.

Code Solution

#include <iostream>
#include <vector>
#include <string>

using namespace std;

struct Contact {
    string nom;
    string telephone;
};

void ajouterContact(vector<Contact>& carnet) {
    Contact c;
    cout << "Nom : ";
    cin >> c.nom;
    cout << "Tel : ";
    cin >> c.telephone;
    carnet.push_back(c);
    cout << "Contact ajoute !\n";
}

void afficherContacts(const vector<Contact>& carnet) {
    for (const auto& c : carnet) {
        cout << "- " << c.nom << " (" << c.telephone << ")\n";
    }
}

int main() {
    vector<Contact> carnet;
    int choix;
    do {
        cout << "\n1. Ajouter  2. Lister  3. Quitter\nChoix: ";
        cin >> choix;
        if (choix == 1) ajouterContact(carnet);
        else if (choix == 2) afficherContacts(carnet);
    } while (choix != 3);
    return 0;
}
Guide : Pourquoi on a fait ça ?

Passage par référence (&) : Dans ajouterContact, on passe vector<Contact>& carnet avec un & pour modifier le vecteur original. Si on oubliait le &, C++ ferait une copie complète du vecteur, ajouterait le contact à la copie, et l'original resterait vide.

Passage par référence constante (const &) : Dans afficherContacts, on utilise const vector<Contact>&. Le & évite de copier tout le vecteur (gain de performance s'il y a 1000 contacts), et le const garantit (et indique aux autres développeurs) que cette fonction ne fera que lire les données sans pouvoir les altérer.

La boucle do-while : Parfaite pour les menus interactifs car elle garantit que le menu s'affiche au moins une fois avant de vérifier la condition de sortie.

02

Parseur de Logs Serveur

Le cas réel : Un serveur web génère des milliers de lignes de log. L'administrateur système a besoin d'un script rapide pour compter combien de fois le mot "ERROR" apparaît dans les logs pour monitorer la santé du système.

Code Solution

#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    // Simulation d'un fichier lu ligne par ligne en mémoire
    vector<string> logs = {
        "INFO: Server started on port 8080",
        "WARNING: High memory usage detected",
        "ERROR: Database connection timeout",
        "INFO: User admin logged in",
        "ERROR: File not found on request /img.png"
    };

    int errorCount = 0;
    for (const auto& line : logs) {
        if (line.find("ERROR") != string::npos) {
            errorCount++;
            cout << "Trouve : " << line << "\n";
        }
    }
    cout << "Total erreurs critiques : " << errorCount << "\n";
    return 0;
}
Guide : Pourquoi on a fait ça ?

Utilisation de find() : La méthode find() de std::string est la méthode standard pour chercher une sous-chaîne. Elle est hautement optimisée.

Pourquoi comparer à string::npos ? : string::npos représente "la fin de la chaîne" ou "non trouvé". Si find ne renvoie pas npos, cela veut dire qu'il a trouvé l'index où le mot commence.

03

Valideur de Mots de Passe

Le cas réel : Lors de l'inscription sur un site web, le backend doit vérifier que le mot de passe fourni par l'utilisateur respecte les règles de sécurité (longueur, présence de chiffres et de majuscules).

Code Solution

#include <iostream>
#include <string>
#include <cctype>

using namespace std;

bool validerMotDePasse(const string& pwd) {
    if (pwd.length() < 8) return false;

    bool aMaj = false;
    bool aChiffre = false;

    for (char c : pwd) {
        if (isupper(c)) aMaj = true;
        if (isdigit(c)) aChiffre = true;
    }
    return aMaj && aChiffre;
}

int main() {
    string pwd;
    cout << "Entrez un mot de passe a tester : ";
    cin >> pwd;

    if (validerMotDePasse(pwd)) {
        cout << "Le mot de passe est valide et securise.\n";
    } else {
        cout << "Invalide (necessite min 8 chars, 1 Maj, 1 Chiffre).\n";
    }
    return 0;
}
Guide : Pourquoi on a fait ça ?

Librairie <cctype> : On utilise isupper et isdigit du C standard. C'est beaucoup plus robuste et lisible que de faire if (c >= 'A' && c <= 'Z').

Early Return : Dès la première ligne de la fonction, on fait if (pwd.length() < 8) return false;. Cela s'appelle un Guard Clause. Si la chaîne est trop courte, on ne perd pas de temps de CPU à parcourir tous les caractères.

04

CLI Calculatrice

Le cas réel : Créer un petit utilitaire appelé depuis d'autres scripts bash pour faire des maths basiques, via les arguments passés directement dans la ligne de commande (ex: ./calc 5 + 3).

Code Solution

#include <iostream>
#include <string>

using namespace std;

int main(int argc, char* argv[]) {
    if (argc != 4) {
        cout << "Usage : ./calc <num1> <op> <num2>\n";
        return 1;
    }

    double a = stod(argv[1]);
    string op = argv[2];
    double b = stod(argv[3]);

    if (op == "+") cout << (a + b) << "\n";
    else if (op == "-") cout << (a - b) << "\n";
    else if (op == "x") cout << (a * b) << "\n"; // x au lieu de * (evite wildcard bash)
    else if (op == "/") {
        if (b != 0) cout << (a / b) << "\n";
        else cout << "Erreur: division par zero\n";
    }
    else {
        cout << "Operateur inconnu.\n";
    }
    return 0;
}
Guide : Pourquoi on a fait ça ?

Utilisation de argc et argv : C'est la méthode C/C++ pour capturer ce que l'utilisateur tape après le nom du programme. argc est le nombre d'arguments (toujours au moins 1, car le nom du programme compte). argv est un tableau de chaînes.

Utilisation de stod() : Les arguments arrivent sous forme de texte (ex: "5"). On utilise stod (String TO Double) pour les convertir en vrais nombres avec virgule.

05

Simulation Bancaire

Le cas réel : Le noyau d'un système bancaire qui doit manipuler des comptes. On doit s'assurer que personne ne peut modifier le solde d'un compte directement sans passer par les opérations officielles de dépôt ou retrait.

Code Solution

#include <iostream>
#include <string>

using namespace std;

class CompteBancaire {
private:
    string titulaire;
    double solde;

public:
    CompteBancaire(string nom, double initial) {
        titulaire = nom;
        solde = (initial > 0) ? initial : 0;
    }

    void deposer(double montant) {
        if (montant > 0) solde += montant;
    }

    bool retirer(double montant) {
        if (montant > 0 && solde >= montant) {
            solde -= montant;
            return true;
        }
        return false;
    }

    void afficher() const {
        cout << "Compte de " << titulaire << " | Solde: " << solde << " EUR\n";
    }
};

int main() {
    CompteBancaire compte("Alice", 100.0);
    compte.afficher();
    compte.deposer(50);
    if (!compte.retirer(200)) cout << "Fonds insuffisants!\n";
    compte.afficher();
    return 0;
}
Guide : Pourquoi on a fait ça ?

Encapsulation (private) : Le solde est privé. C'est essentiel dans le monde réel ! Si on le laissait public, n'importe quelle autre partie du code pourrait faire compte.solde = 9999999;, créant une énorme faille. On oblige le reste de l'application à utiliser deposer et retirer, où l'on peut ajouter des contrôles (ex: on ne dépose pas de montants négatifs).

Constructeur sécurisé : L'opérateur ternaire (initial > 0) ? initial : 0 empêche la création d'un compte avec un solde négatif dès le départ.

06

Convertisseur de Devises

Le cas réel : Une boutique e-commerce permet de changer la devise d'affichage. Il faut un système simple basés sur un tableau de taux de change.

Code Solution

#include <iostream>
#include <map>
#include <string>

using namespace std;

int main() {
    map<string, double> taux = {
        {"USD", 1.09},
        {"GBP", 0.85},
        {"JPY", 160.40}
    };

    double euros;
    cout << "Montant en EUR : ";
    cin >> euros;

    cout << "Equivalents :\n";
    for (const auto& paire : taux) {
        cout << euros * paire.second << " " << paire.first << "\n";
    }
    return 0;
}
Guide : Pourquoi on a fait ça ?

Utilisation de std::map : Le dictionnaire clé-valeur (map) est parfait pour associer un nom de devise à son taux. Cela évite d'utiliser des blocs de if-else géants et permet d'ajouter de nouvelles devises très facilement.

La boucle for-each sur une map : Chaque itération donne une paire. paire.first accède à la clé ("USD"), et paire.second accède à la valeur (1.09).

07

Lecteur CSV Simple

Le cas réel : Les données métier sont souvent exportées en CSV. L'application doit lire des lignes de texte séparées par des virgules pour en extraire l'information brute.

Code Solution

#include <iostream>
#include <sstream>
#include <string>

using namespace std;

int main() {
    string ligneCsv = "Durand,Jean,45,Paris";
    stringstream ss(ligneCsv);
    string token;

    cout << "Extraction des donnees:\n";
    while (getline(ss, token, ',')) {
        cout << "- " << token << "\n";
    }
    return 0;
}
Guide : Pourquoi on a fait ça ?

Utilisation de stringstream : Un flux de chaîne (stringstream) permet de traiter une chaîne de caractères en mémoire comme s'il s'agissait d'un fichier. C'est l'outil canonique en C++ pour parser du texte avec des délimiteurs.

getline avec un 3ème argument : En passant ',', on demande à getline de s'arrêter à la virgule plutôt qu'au saut de ligne.

08

Tic-Tac-Toe Console

Le cas réel : Développer un petit jeu dans le terminal. Cela apprend à gérer des grilles (tableaux 2D) et l'état global d'une application (Game Loop).

Code Solution

#include <iostream>
using namespace std;

void afficherGrille(char g[3][3]) {
    for(int i=0; i<3; i++) {
        cout << g[i][0] << "|" << g[i][1] << "|" << g[i][2] << "\n";
        if(i<2) cout << "-----\n";
    }
}

int main() {
    char grille[3][3] = {{'1','2','3'}, {'4','5','6'}, {'7','8','9'}};
    int tour = 0;
    char joueur = 'X';

    while(tour < 9) {
        afficherGrille(grille);
        cout << "Joueur " << joueur << ", choisissez une case (1-9): ";
        int choix; cin >> choix;
        int r = (choix-1)/3;
        int c = (choix-1)%3;
        
        if(grille[r][c] != 'X' && grille[r][c] != 'O') {
            grille[r][c] = joueur;
            joueur = (joueur == 'X') ? 'O' : 'X';
            tour++;
        } else {
            cout << "Case occupee!\n";
        }
    }
    cout << "Fin du jeu!\n";
    return 0;
}
Guide : Pourquoi on a fait ça ?

Maths de conversion 1D-2D : La formule r = (choix-1)/3 et c = (choix-1)%3 est une astuce mathématique classique pour transformer un index linéaire (1 à 9) en coordonnées X,Y pour un tableau 2D, évitant un énorme switch-case.

Ternaire pour changer de joueur : (joueur == 'X') ? 'O' : 'X' est un moyen propre et concis d'alterner les joueurs à chaque tour valide.

09

Réservation Cinéma

Le cas réel : Un cinéma veut un outil de gestion des places dans une salle. Si une place est déjà vendue, on ne peut plus la réserver.

Code Solution

#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 10 places dans la salle, false = libre, true = reserve
    vector<bool> places(10, false);
    
    int choix;
    while(true) {
        cout << "\nPlaces libres : ";
        for(int i=0; i<places.size(); i++) {
            if(!places[i]) cout << (i+1) << " ";
        }
        cout << "\nReserver le siege numero (0 pour quitter) : ";
        cin >> choix;
        
        if (choix == 0) break;
        if (choix < 1 || choix > 10) cout << "Invalide.\n";
        else if (places[choix-1]) cout << "Deja reserve!\n";
        else {
            places[choix-1] = true;
            cout << "Reservation validee.\n";
        }
    }
    return 0;
}
Guide : Pourquoi on a fait ça ?

vector<bool> initialisé avec une taille : vector<bool> places(10, false) permet de créer directement un vecteur de 10 éléments, tous mis à false. C'est plus propre que de faire une boucle de 10 push_back.

Ajustement d'index : Le client voit les sièges de 1 à 10, mais les tableaux commencent à l'index 0. D'où le places[choix-1] obligatoire.

10

Tracker de Dépenses

Le cas réel : Une app d'aggrégation financière qui accumule les petites dépenses d'une journée et calcule un total.

Code Solution

#include <iostream>
#include <numeric>
#include <vector>

using namespace std;

int main() {
    vector<double> depenses;
    double saisie;

    cout << "Entrez vos depenses (0 pour terminer) :\n";
    while (true) {
        cin >> saisie;
        if (saisie == 0) break;
        depenses.push_back(saisie);
    }

    double total = accumulate(depenses.begin(), depenses.end(), 0.0);
    
    cout << "Vous avez fait " << depenses.size() << " depenses.\n";
    cout << "Total de la journee : " << total << " EUR\n";

    return 0;
}
Guide : Pourquoi on a fait ça ?

Utilisation de std::accumulate : Issue de la librairie <numeric>, cette fonction parcourt tout un conteneur et additionne les éléments. C'est du "Modern C++" : on préfère utiliser les algorithmes standards très optimisés plutôt que d'écrire des boucles for soi-même pour faire des sommes.

Le 0.0 dans accumulate : Le troisième paramètre est la valeur de départ. Mettre 0.0 (et non 0) indique au compilateur que l'on manipule des nombres à virgule (double), évitant des troncatures intempestives (perte des centimes).
