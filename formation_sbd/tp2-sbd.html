Séance 2 — 4 heures

Requêtes Avancées & Jointures

Une base de données relationnelle prend tout son sens quand on relie les tables entre elles. Découvrez les filtres avancés et la clause JOIN.

1. Exercice Guidé : Lier deux tables (Clé Étrangère et JOIN)

Nous avons une table livres et une table adherents. Comment savoir quel adhérent a emprunté quel livre ? On ne va pas tout mettre dans la même table, on va créer une troisième table pour faire le lien !

Étape 1 : Créer la table de liaison (Emprunts)

USE bibliotheque_db;

CREATE TABLE emprunts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    adherent_id INT,
    livre_id INT,
    date_emprunt DATE,
    FOREIGN KEY (adherent_id) REFERENCES adherents(id),
    FOREIGN KEY (livre_id) REFERENCES livres(id)
);

Les mots-clés FOREIGN KEY indiquent à MySQL : "Attention, le chiffre dans adherent_id DOIT correspondre à un ID qui existe vraiment dans la table adherents".

Étape 2 : Enregistrer un emprunt

Admettons que l'adhérent numéro 1 (Pauline) emprunte le livre numéro 3 (Harry Potter) aujourd'hui.

INSERT INTO emprunts (adherent_id, livre_id, date_emprunt) 
VALUES (1, 3, '2023-10-25');

Étape 3 : La requête magique (INNER JOIN)

Si on fait un simple SELECT * FROM emprunts, on ne verra que des chiffres (1, 3). Pour afficher les vrais noms, on utilise INNER JOIN.

SELECT adherents.nom_complet, livres.titre, emprunts.date_emprunt
FROM emprunts
INNER JOIN adherents ON emprunts.adherent_id = adherents.id
INNER JOIN livres ON emprunts.livre_id = livres.id;
L'astuce : Dans la clause ON, on dit à MySQL comment faire correspondre les deux pièces du puzzle (la clé étrangère de la table A = l'ID principal de la table B).

2. Travaux Pratiques (10 exercices)

Assurez-vous d'avoir exécuté l'exercice guidé. Vous allez maintenant pratiquer les filtres avancés et les différents types de jointures.

TP 01

Filtre textuel partiel (LIKE)

Affichez tous les livres dont le titre contient le mot "Prince".

▶ Voir la solution 
-- Le symbole % remplace "n'importe quel nombre de caractères"
SELECT * FROM livres 
WHERE titre LIKE '%Prince%';
TP 02

Listes de valeurs (IN)

Affichez les livres écrits par "J.K. Rowling" ou par "Victor Hugo" en utilisant la clause IN au lieu de faire plusieurs OR.

▶ Voir la solution 
SELECT titre, auteur FROM livres 
WHERE auteur IN ('J.K. Rowling', 'Victor Hugo');
TP 03

Intervalles (BETWEEN)

Affichez les livres publiés entre 1900 et 1999.

▶ Voir la solution 
SELECT * FROM livres 
WHERE annee_publication BETWEEN 1900 AND 1999;
TP 04

Plusieurs conditions (AND, OR)

Trouvez les livres qui coûtent moins de 12 euros ET qui ont été écrits avant 1950.

▶ Voir la solution 
SELECT titre, prix, annee_publication FROM livres 
WHERE prix < 12.00 AND annee_publication < 1950;
TP 05

Utiliser les ALIAS (AS) pour raccourcir le code

Réécrivez la requête de jointure (Étape 3 du guide) en utilisant des "Alias" (des surnoms très courts d'une lettre pour les tables) pour que le code soit plus lisible.

▶ Voir la solution 
SELECT a.nom_complet, l.titre, e.date_emprunt
FROM emprunts AS e
INNER JOIN adherents AS a ON e.adherent_id = a.id
INNER JOIN livres AS l ON e.livre_id = l.id;

-- Note : Le mot clé "AS" est facultatif pour les tables, on peut juste écrire "emprunts e"
TP 06

Rajouter une nouvelle catégorie

On veut classer les livres. Ajoutez une table categories (id, nom) et insérez "Roman", "Science-Fiction", et "Jeunesse".

▶ Voir la solution 
CREATE TABLE categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom VARCHAR(50) NOT NULL
);

INSERT INTO categories (nom) VALUES ('Roman'), ('Science-Fiction'), ('Jeunesse');
TP 07

Modifier une table existante pour l'associer

Ajoutez une colonne categorie_id à la table livres, et définissez-la comme clé étrangère vers la table categories.

▶ Voir la solution 
ALTER TABLE livres ADD COLUMN categorie_id INT;

ALTER TABLE livres 
ADD FOREIGN KEY (categorie_id) REFERENCES categories(id);
TP 08

Mise à jour massive (UPDATE)

Attribuez la catégorie 1 ("Roman") à tous les livres sauf Harry Potter, qui aura la catégorie 3 ("Jeunesse").

▶ Voir la solution 
UPDATE livres SET categorie_id = 1;
UPDATE livres SET categorie_id = 3 WHERE titre = 'Harry Potter';
TP 09

LEFT JOIN (Garder tout le monde)

Insérez un nouveau livre sans catégorie (laissez categorie_id à NULL). Puis faites un LEFT JOIN entre livres et categories. Que remarquez-vous par rapport à un INNER JOIN ?

▶ Voir la solution 
INSERT INTO livres (titre, auteur, annee_publication, prix) 
VALUES ('Le Guide du Voyageur', 'Douglas Adams', 1979, 9.99);
-- (Ici categorie_id est automatiquement NULL car on ne l'a pas précisé)

SELECT l.titre, c.nom AS categorie
FROM livres l
LEFT JOIN categories c ON l.categorie_id = c.id;

-- Explication : Le livre apparaît dans les résultats avec une catégorie "NULL". 
-- Si on avait utilisé INNER JOIN, ce livre aurait disparu des résultats car l'INNER JOIN exige que le lien existe des deux côtés !
TP 10

Trouver les "Orphelins" (IS NULL)

En utilisant la requête précédente et un filtre spécial IS NULL, affichez UNIQUEMENT les livres qui n'ont pas encore été classés dans une catégorie.

▶ Voir la solution 
SELECT l.titre 
FROM livres l
LEFT JOIN categories c ON l.categorie_id = c.id
WHERE c.id IS NULL; 

-- Ou plus simplement, sans jointure :
SELECT titre FROM livres WHERE categorie_id IS NULL;
