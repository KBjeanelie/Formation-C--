Guide de Survie

Cheatsheet Initiation SQL

Un aide-mémoire complet pour maîtriser les bases du langage SQL et la conception de tables.

1. Les Commandes CLI (Terminal)

  • SHOW DATABASES; : Lister toutes les bases de données.
  • USE ma_base; : Se connecter à la base "ma_base".
  • SHOW TABLES; : Lister toutes les tables de la base actuelle.
  • DESCRIBE ma_table; : Voir la structure d'une table (colonnes, types).

2. Création de Tables & Types de base

CREATE DATABASE mon_projet;
USE mon_projet;

CREATE TABLE etudiants (
    id INT AUTO_INCREMENT PRIMARY KEY, -- Identifiant unique automatique
    nom VARCHAR(50) NOT NULL,          -- Texte de max 50 caractères, obligatoire
    prenom VARCHAR(50),                -- Texte facultatif (peut être NULL)
    age INT CHECK (age >= 18),         -- Entier avec condition
    moyenne DECIMAL(4,2),              -- Nombre à virgule (ex: 15.50)
    date_inscription DATE DEFAULT CURRENT_DATE
);

3. Opérations CRUD (Manipulation)

Insertion (CREATE)

INSERT INTO etudiants (nom, prenom, age, moyenne) 
VALUES ('Dupont', 'Jean', 20, 14.50),
       ('Martin', 'Alice', 22, 16.00);

Lecture (READ)

-- Lire tout
SELECT * FROM etudiants;

-- Lire avec filtre et tri
SELECT nom, prenom FROM etudiants 
WHERE age >= 20 
ORDER BY moyenne DESC;

Mise à jour (UPDATE)

UPDATE etudiants 
SET moyenne = 18.00 
WHERE nom = 'Dupont';

Suppression (DELETE)

DELETE FROM etudiants WHERE age < 18;

4. Jointures (Relations entre tables)

-- Table filière
CREATE TABLE filieres (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom_filiere VARCHAR(50)
);

-- Etudiant appartient à une filière (Clé Etrangère)
ALTER TABLE etudiants ADD filiere_id INT;
ALTER TABLE etudiants ADD FOREIGN KEY (filiere_id) REFERENCES filieres(id);

-- La requête INNER JOIN (récupérer les étudiants AVEC le nom de leur filière)
SELECT e.nom, e.prenom, f.nom_filiere 
FROM etudiants e
INNER JOIN filieres f ON e.filiere_id = f.id;

5. Fonctions d'Agrégation & Regroupement

-- Compter le nombre total d'étudiants
SELECT COUNT(*) FROM etudiants;

-- Calculer la moyenne générale de tous les étudiants
SELECT AVG(moyenne) FROM etudiants;

-- Afficher la moyenne par filière (GROUP BY)
SELECT f.nom_filiere, AVG(e.moyenne) AS moyenne_filiere
FROM etudiants e
INNER JOIN filieres f ON e.filiere_id = f.id
GROUP BY f.nom_filiere;
