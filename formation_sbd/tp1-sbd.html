Séance 1 — 4 heures

Initiation : DDL & CRUD de base

Découvrez comment créer la structure d'une base de données et manipuler vos premières informations. Vous apprendrez à créer, lire, mettre à jour et supprimer (CRUD).

1. Exercice Guidé (Travail Dirigé)

Avant de vous lancer dans les TPs, réalisons ensemble la conception d'un petit annuaire.

Étape 1 : Création de la Base de Données

Ouvrez votre client (Workbench ou DBeaver). Nous allons dire à MySQL de créer un nouvel espace de stockage appelé annuaire et de s'y connecter.

CREATE DATABASE annuaire;
USE annuaire;

Étape 2 : Création de la table (DDL)

Dans cette base, nous voulons stocker des "contacts". Il faut d'abord définir la structure de la table, c'est ce qu'on appelle le Data Definition Language (DDL). On précise le type de chaque donnée :

CREATE TABLE contacts (
    id INT AUTO_INCREMENT PRIMARY KEY, -- L'ID se gère tout seul (1, 2, 3...)
    nom VARCHAR(50) NOT NULL,          -- Chaîne de texte (max 50) obligatoire
    telephone VARCHAR(15),             -- Chaîne pour numéro, facultatif
    date_ajout DATE                    -- Stocke l'année, le mois, le jour
);

Étape 3 : Insérer des données (INSERT)

Maintenant que la boîte est créée, mettons-y des informations (Data Manipulation Language - DML).

INSERT INTO contacts (nom, telephone, date_ajout) 
VALUES ('Jean Dupont', '0601020304', '2023-01-15');

INSERT INTO contacts (nom, telephone, date_ajout) 
VALUES ('Alice Martin', '0711223344', '2023-02-20');

Étape 4 : Interroger les données (SELECT)

Pour voir ce qu'il y a dans notre table, on utilise la commande SELECT.

-- Voir TOUT le contenu de la table
SELECT * FROM contacts;

-- Voir uniquement les noms
SELECT nom FROM contacts;
Vous avez compris ? Vous savez maintenant créer une base, une table, y mettre des données et les lire. C'est la base absolue des bases de données relationnelles ! Place aux TPs.

2. Travaux Pratiques (10 exercices)

Pour ces TPs, nous allons créer un système de gestion pour une Bibliothèque Municipale. Suivez les TPs dans l'ordre !

TP 01

Créer l'espace de travail

Créez une base de données nommée bibliotheque_db et connectez-vous y.

▶ Voir la solution 
CREATE DATABASE bibliotheque_db;
USE bibliotheque_db;
TP 02

Créer la table des Livres

Créez une table livres contenant un identifiant automatique, un titre (100 char max, obligatoire), un auteur (50 char max), et une annee_publication de type entier (INT).

▶ Voir la solution 
CREATE TABLE livres (
    id INT AUTO_INCREMENT PRIMARY KEY,
    titre VARCHAR(100) NOT NULL,
    auteur VARCHAR(50),
    annee_publication INT
);
TP 03

Ajouter le type de données approprié

Oups, nous avons oublié le prix du livre ! Utilisez la commande ALTER TABLE pour ajouter une colonne prix capable de stocker des nombres à virgule (par exemple 15.50).

▶ Voir la solution 
ALTER TABLE livres 
ADD COLUMN prix DECIMAL(5,2); 
-- 5 chiffres au total, dont 2 après la virgule (ex: 125.50)
TP 04

Peupler la bibliothèque

Insérez au moins 4 livres dans la table. Assurez-vous d'insérer le titre, l'auteur, l'année et le prix.

▶ Voir la solution 
INSERT INTO livres (titre, auteur, annee_publication, prix) VALUES
('Le Petit Prince', 'Antoine de Saint-Exupéry', 1943, 8.50),
('1984', 'George Orwell', 1949, 10.00),
('Harry Potter', 'J.K. Rowling', 1997, 15.99),
('Les Misérables', 'George Orwell', 1862, 12.00);
TP 05

Correction d'erreur (UPDATE)

Dans l'insertion précédente, il y a une erreur : "Les Misérables" a été écrit par Victor Hugo, pas George Orwell ! Mettez à jour ce livre sans toucher aux autres.

▶ Voir la solution 
UPDATE livres 
SET auteur = 'Victor Hugo' 
WHERE titre = 'Les Misérables';
TP 06

Lire les données avec condition

Écrivez une requête SELECT pour afficher uniquement les livres qui coûtent plus de 10 euros.

▶ Voir la solution 
SELECT * FROM livres 
WHERE prix > 10.00;
TP 07

Trier les résultats

Affichez le titre et l'auteur de tous les livres, triés du plus ancien au plus récent (selon l'année de publication).

▶ Voir la solution 
SELECT titre, auteur 
FROM livres 
ORDER BY annee_publication ASC; 
-- (ASC = Ascendant, c'est le comportement par défaut)
TP 08

Ajouter la table des Adhérents

Créez une table adherents contenant un ID auto, un nom_complet (VARCHAR 100) et une colonne date_naissance (DATE).

▶ Voir la solution 
CREATE TABLE adherents (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom_complet VARCHAR(100) NOT NULL,
    date_naissance DATE
);
TP 09

Insérer des dates

Insérez deux adhérents. Note : le format MySQL pour les dates est toujours 'YYYY-MM-DD' (Année-Mois-Jour).

▶ Voir la solution 
INSERT INTO adherents (nom_complet, date_naissance) VALUES
('Pauline Bernard', '1990-05-14'),
('Lucas Dubois', '2005-11-20');
TP 10

Le grand nettoyage (DELETE)

Un adhérent s'est désinscrit. Supprimez l'adhérent "Lucas Dubois" de la base de données de manière propre (via la clause WHERE).

▶ Voir la solution 
DELETE FROM adherents 
WHERE nom_complet = 'Lucas Dubois';

-- Vérification :
SELECT * FROM adherents;
