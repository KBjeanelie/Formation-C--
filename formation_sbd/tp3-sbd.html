Séance 3 — 4 heures

Agrégations & Sous-requêtes

Apprenez à regrouper les données pour en extraire des statistiques (moyenne, somme, comptage) et à imbriquer des requêtes les unes dans les autres.

1. Exercice Guidé : Les statistiques avec GROUP BY

Le SQL ne sert pas qu'à lire des lignes brutes, il excelle pour faire des calculs statistiques. Continuons sur notre base bibliotheque_db !

Étape 1 : Les Fonctions d'Agrégation (Max, Min, Avg, Sum, Count)

Ces fonctions permettent d'écraser plusieurs lignes en une seule valeur mathématique.

USE bibliotheque_db;

-- Combien avons-nous de livres en tout ?
SELECT COUNT(*) FROM livres;

-- Quel est le prix du livre le plus cher ?
SELECT MAX(prix) FROM livres;

Étape 2 : Grouper les données avec GROUP BY

Si on veut savoir "Combien de livres avons-nous par catégorie ?", on doit "grouper" les calculs selon cette catégorie.

SELECT c.nom AS Categorie, COUNT(l.id) AS NombreDeLivres
FROM categories c
LEFT JOIN livres l ON c.id = l.categorie_id
GROUP BY c.nom;

Étape 3 : Filtrer sur un groupe avec HAVING

Le WHERE filtre avant le calcul. Le HAVING filtre après le calcul mathématique ! Par exemple : "Afficher uniquement les catégories qui ont plus de 1 livre."

SELECT c.nom AS Categorie, COUNT(l.id) AS NombreDeLivres
FROM categories c
LEFT JOIN livres l ON c.id = l.categorie_id
GROUP BY c.nom
HAVING COUNT(l.id) > 1;
Règle d'or : Dès que vous utilisez un GROUP BY, toutes les colonnes du SELECT qui ne sont pas dans une fonction mathématique (COUNT, SUM...) doivent obligatoirement apparaître dans le GROUP BY !

2. Travaux Pratiques (10 exercices)

TP 01

Calcul de la somme (SUM)

Quelle est la valeur totale (somme des prix) de tous les livres de notre bibliothèque ?

▶ Voir la solution 
SELECT SUM(prix) AS ValeurTotale 
FROM livres;
TP 02

Calcul de la moyenne (AVG)

Quel est le prix moyen d'un livre dans cette bibliothèque ?

▶ Voir la solution 
SELECT AVG(prix) AS PrixMoyen 
FROM livres;
TP 03

La plus ancienne publication (MIN)

Affichez l'année de publication du plus vieux livre de la table.

▶ Voir la solution 
SELECT MIN(annee_publication) AS PlusVieux 
FROM livres;
TP 04

Sous-requête simple : Trouver le livre le plus vieux

La question précédente nous a donné l'année (1862). Mais comment obtenir le titre du livre le plus vieux ? On imbrique une requête dans une autre !

▶ Voir la solution 
SELECT titre, annee_publication 
FROM livres
WHERE annee_publication = (
    SELECT MIN(annee_publication) FROM livres
);
TP 05

Grouper par Auteur

Affichez le nom de chaque auteur, suivi du nombre de livres que nous possédons pour cet auteur.

▶ Voir la solution 
SELECT auteur, COUNT(*) AS Nombre_Oeuvres
FROM livres
GROUP BY auteur;
TP 06

Filtrer un groupe (HAVING)

Reprenez la requête précédente, mais n'affichez que les auteurs pour lesquels nous possédons STRICTEMENT PLUS d'un livre (donc 2 ou plus).

▶ Voir la solution 
SELECT auteur, COUNT(*) AS Nombre_Oeuvres
FROM livres
GROUP BY auteur
HAVING COUNT(*) > 1;
TP 07

Moyenne des prix par catégorie

Affichez le nom de chaque catégorie avec le prix moyen de ses livres. Utilisez ROUND() pour n'avoir que 2 chiffres après la virgule.

▶ Voir la solution 
SELECT c.nom AS Categorie, ROUND(AVG(l.prix), 2) AS Prix_Moyen
FROM categories c
INNER JOIN livres l ON c.id = l.categorie_id
GROUP BY c.nom;
TP 08

Sous-requête : Livres plus chers que la moyenne

Trouvez le titre et le prix de tous les livres dont le prix est supérieur au prix moyen de toute la bibliothèque.

▶ Voir la solution 
SELECT titre, prix 
FROM livres
WHERE prix > (
    SELECT AVG(prix) FROM livres
);
TP 09

Sous-requête avec IN

Affichez le nom complet des adhérents qui ont emprunté un livre de la catégorie "Roman". (Vous pouvez le faire avec 3 jointures, ou avec une sous-requête !)

▶ Voir la solution 
-- Méthode Sous-requête (souvent plus claire à lire) :
SELECT nom_complet FROM adherents 
WHERE id IN (
    SELECT adherent_id FROM emprunts WHERE livre_id IN (
        SELECT id FROM livres WHERE categorie_id = (
            SELECT id FROM categories WHERE nom = 'Roman'
        )
    )
);

-- Ou méthode avec Jointures :
SELECT a.nom_complet 
FROM adherents a
INNER JOIN emprunts e ON a.id = e.adherent_id
INNER JOIN livres l ON e.livre_id = l.id
INNER JOIN categories c ON l.categorie_id = c.id
WHERE c.nom = 'Roman';
TP 10

Créer une Vue (Raccourci permanent)

Une vue (VIEW) permet de sauvegarder une requête complexe comme si c'était une table virtuelle. Créez une vue appelée vue_stock_bibliotheque qui affiche la somme totale des prix par auteur, puis faites un SELECT * FROM vue_stock_bibliotheque pour tester.

▶ Voir la solution 
CREATE VIEW vue_stock_bibliotheque AS
SELECT auteur, SUM(prix) AS valeur_totale
FROM livres
GROUP BY auteur;

-- On peut maintenant interroger cette vue n'importe quand !
SELECT * FROM vue_stock_bibliotheque ORDER BY valeur_totale DESC;
