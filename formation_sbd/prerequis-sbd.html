Préparation

Installation de MySQL

Windows

1. Téléchargez MySQL Installer sur dev.mysql.com.

2. Lancez l'installation en choisissant "Developer Default" (ou "Custom" pour ne prendre que MySQL Server et MySQL Workbench).

3. Laissez les ports par défaut (3306).

4. Très important : Un mot de passe pour l'utilisateur superadmin root vous sera demandé. Notez-le soigneusement !

Linux (Ubuntu / Debian)

Ouvrez votre terminal et tapez :

sudo apt update
sudo apt install mysql-server

Sécurisez l'installation (mot de passe root, suppression des utilisateurs anonymes) :

sudo mysql_secure_installation

macOS

La méthode la plus simple est d'utiliser Homebrew :

brew install mysql
brew services start mysql

Pour sécuriser l'installation :

mysql_secure_installation

L'interface graphique (Client SQL)

Pour écrire vos requêtes de manière confortable, il vous faut un client. Deux excellents choix :

  • MySQL Workbench : L'outil officiel de conception et d'administration, souvent installé avec MySQL sous Windows.
  • DBeaver (Recommandé) : Client universel très léger et puissant. Téléchargeable sur dbeaver.io.

Pour vous connecter dans Workbench ou DBeaver : Hôte : localhost, Port : 3306, Utilisateur : root, et votre mot de passe.
