01

Objectifs de la séance

  • Comprendre la différence entre une classe (le modèle) et un objet (une instance concrète).
  • Déclarer des attributs et des méthodes.
  • Écrire des constructeurs pour initialiser un objet à sa création.
  • Appliquer l'encapsulation avec private et public, et écrire des accesseurs / mutateurs (getters / setters).
  • Manipuler plusieurs objets d'une même classe dans un programme.
02

Classes et objets

Une classe décrit un type sur mesure : quels attributs (données) et quelles méthodes (comportements) possèdent ses objets.
class Personne {
public:
    std::string nom;
    int age;

    void sePresenter() {
        std::cout << "Je m'appelle " << nom << " et j'ai " << age << " ans." << std::endl;
    }
};

int main() {
    Personne p1;
    p1.nom = "Sarah";
    p1.age = 24;
    p1.sePresenter();

    return 0;
}

p1 est un objet — une instance de la classe Personne. On peut créer autant d'objets que nécessaire à partir de la même classe, chacun avec ses propres valeurs.

03

Constructeurs

Un constructeur porte le même nom que la classe et s'exécute automatiquement à la création d'un objet, pour l'initialiser proprement :

class Personne {
public:
    std::string nom;
    int age;

    // constructeur
    Personne(std::string n, int a) {
        nom = n;
        age = a;
    }

    void sePresenter() {
        std::cout << nom << ", " << age << " ans" << std::endl;
    }
};

int main() {
    Personne p1("Sarah", 24);
    Personne p2("Karim", 31);
    p1.sePresenter();
    p2.sePresenter();

    return 0;
}
À retenir : une classe peut avoir plusieurs constructeurs avec des listes de paramètres différentes (surcharge), y compris un constructeur sans paramètre.
04

Encapsulation

Un attribut private n'est accessible que depuis l'intérieur de la classe. On y accède de l'extérieur via des méthodes publiques dédiées : les getters (lecture) et setters (écriture), qui permettent au passage de valider les valeurs.

class CompteBancaire {
private:
    double solde;

public:
    CompteBancaire(double soldeInitial) {
        solde = soldeInitial;
    }

    double getSolde() {
        return solde;
    }

    void deposer(double montant) {
        if (montant > 0) {
            solde += montant;
        }
    }
};
Mot-cléAccès
privateUniquement depuis les méthodes de la classe elle-même
publicDepuis n'importe où dans le programme
Pourquoi encapsuler ? Un solde public pourrait être modifié n'importe comment depuis l'extérieur (compte.solde = -500;). En le rendant privé et en passant par deposer(), on garde le contrôle sur les règles métier.

Ex. 2

Classe Rectangle avec constructeur

facile

Reprendre la classe Rectangle de l'exercice 1 et lui ajouter un constructeur qui initialise largeur et hauteur à la création, ainsi qu'une méthode perimetre().

Voir la solution 
#include <iostream>

class Rectangle {
public:
    double largeur;
    double hauteur;

    Rectangle(double l, double h) {
        largeur = l;
        hauteur = h;
    }

    double aire() {
        return largeur * hauteur;
    }

    double perimetre() {
        return 2 * (largeur + hauteur);
    }
};

int main() {
    Rectangle r1(4, 3);
    std::cout << "Aire : " << r1.aire() << std::endl;
    std::cout << "Périmètre : " << r1.perimetre() << std::endl;

    return 0;
}
Ex. 3

Classe CompteBancaire

intermédiaire

Créer une classe CompteBancaire avec un attribut privé solde, un constructeur prenant le solde initial, une méthode deposer(double montant), une méthode retirer(double montant) qui refuse le retrait si le solde est insuffisant, et un getter getSolde().

Voir la solution 
#include <iostream>

class CompteBancaire {
private:
    double solde;

public:
    CompteBancaire(double soldeInitial) {
        solde = soldeInitial;
    }

    void deposer(double montant) {
        if (montant > 0) {
            solde += montant;
        }
    }

    void retirer(double montant) {
        if (montant > 0 && montant <= solde) {
            solde -= montant;
        } else {
            std::cout << "Retrait refusé : solde insuffisant." << std::endl;
        }
    }

    double getSolde() {
        return solde;
    }
};

int main() {
    CompteBancaire compte(10000);
    compte.deposer(5000);
    compte.retirer(3000);
    compte.retirer(50000);

    std::cout << "Solde final : " << compte.getSolde() << " FCFA" << std::endl;

    return 0;
}
Ex. 4

Classe Etudiant et moyenne

intermédiaire

Créer une classe Etudiant avec un attribut privé nom et un tableau privé de 3 notes. Ajouter un constructeur, une méthode moyenne() qui retourne la moyenne des notes, et une méthode afficher() qui affiche le nom et la moyenne.

Voir la solution 
#include <iostream>

class Etudiant {
private:
    std::string nom;
    double notes[3];

public:
    Etudiant(std::string n, double n1, double n2, double n3) {
        nom = n;
        notes[0] = n1;
        notes[1] = n2;
        notes[2] = n3;
    }

    double moyenne() {
        return (notes[0] + notes[1] + notes[2]) / 3;
    }

    void afficher() {
        std::cout << nom << " — moyenne : " << moyenne() << std::endl;
    }
};

int main() {
    Etudiant e1("Paul", 14, 16, 12);
    e1.afficher();

    return 0;
}
Ex. 5

Classe Point et distance

intermédiaire

Créer une classe Point avec des attributs privés x et y, un constructeur, des getters, et une méthode distance(Point autre) qui calcule la distance euclidienne entre deux points (formule : racine carrée de (x2-x1)² + (y2-y1)², avec #include <cmath> et sqrt()).

Voir la solution 
#include <iostream>
#include <cmath>

class Point {
private:
    double x, y;

public:
    Point(double px, double py) {
        x = px;
        y = py;
    }

    double getX() { return x; }
    double getY() { return y; }

    double distance(Point autre) {
        double dx = autre.getX() - x;
        double dy = autre.getY() - y;
        return sqrt(dx * dx + dy * dy);
    }
};

int main() {
    Point a(0, 0);
    Point b(3, 4);

    std::cout << "Distance : " << a.distance(b) << std::endl;

    return 0;
}

Résultat attendu : 5, puisque le triangle (0,0)-(3,0)-(3,4) est un triangle 3-4-5.

Ex. 6

Gestion d'un petit stock

défi

Créer une classe Produit avec des attributs privés nom, prixUnitaire et quantite. Ajouter un constructeur, une méthode valeurStock() qui retourne prixUnitaire * quantite, et une méthode vendre(int qte) qui diminue la quantité si le stock est suffisant, sinon affiche un message d'erreur. Dans main, créer un tableau de 3 Produit et afficher la valeur totale du stock.

Voir la solution 
#include <iostream>

class Produit {
private:
    std::string nom;
    double prixUnitaire;
    int quantite;

public:
    Produit(std::string n, double prix, int qte) {
        nom = n;
        prixUnitaire = prix;
        quantite = qte;
    }

    double valeurStock() {
        return prixUnitaire * quantite;
    }

    void vendre(int qte) {
        if (qte <= quantite) {
            quantite -= qte;
        } else {
            std::cout << "Stock insuffisant pour " << nom << std::endl;
        }
    }

    double getValeur() { return valeurStock(); }
};

int main() {
    Produit stock[3] = {
        Produit("Cahier", 500, 40),
        Produit("Stylo", 150, 100),
        Produit("Classeur", 1200, 15)
    };

    double total = 0;
    for (int i = 0; i < 3; i++) {
        total += stock[i].getValeur();
    }

    std::cout << "Valeur totale du stock : " << total << " FCFA" << std::endl;

    return 0;
}

Cet exercice combine tableau d'objets, constructeur, encapsulation et méthodes — une bonne préparation pour l'héritage et la STL de la séance 4.
