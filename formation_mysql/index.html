Bases de Données (MySQL L3)

Formation axée 100% TP sur l'optimisation, la programmation serveur (MySQL 8+) et l'introduction au NoSQL.

Prérequis

Installation MySQL

Configurez MySQL Server et MySQL Workbench sur Windows, macOS ou Linux.

 Guide / Doc

Cheatsheet MySQL

Rappels : Création de bases, AUTO_INCREMENT, types de données, commandes CLI de survie et gestion utilisateurs.

 Séance 1 (4h)

Routines & Triggers

Écrivez de la logique côté serveur. Procédures stockées (DELIMITER) et triggers d'audit (FOR EACH ROW) sur un modèle e-commerce.

 Séance 2 (4h)

Sécurité & Transactions

Gestion des rôles (MySQL 8) et simulation d'un système bancaire transactionnel (START TRANSACTION / COMMIT / ROLLBACK).

 Séance 3 (4h)

Crash Test & Indexation

Générez 2 millions de lignes avec une boucle, lisez les plans d'exécution (EXPLAIN) et optimisez avec des index B-Tree.

 Séance 4 (4h)

Bascule vers le NoSQL

Introduction à MongoDB. Stockage orienté document (JSON), requêtes CRUD et pipeline d'agrégation.
