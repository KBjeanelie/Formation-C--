Guide de Survie

Cheatsheet MySQL

Un aide-mémoire complet pour retrouver ses marques de 0 à expert. Idéal pour se rafraîchir la mémoire avant de démarrer la Séance 1.

1. Les Commandes CLI (Terminal)

Si vous utilisez l'outil en ligne de commande mysql -u root -p :

  • SHOW DATABASES; : Lister toutes les bases de données.
  • USE ma_base; : Se connecter à la base "ma_base".
  • SHOW TABLES; : Lister toutes les tables de la base actuelle.
  • DESCRIBE ma_table; : Voir la structure d'une table (colonnes, types).
  • EXIT; ou \q : Quitter mysql.

2. Bases de Données

-- Créer une base de données avec encodage UTF-8 complet
CREATE DATABASE e_commerce CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- S'y connecter
USE e_commerce;

3. Création de Tables & Types de base

L'auto-incrémentation se fait avec le mot-clé AUTO_INCREMENT.

CREATE TABLE employes (
    id INT AUTO_INCREMENT PRIMARY KEY, -- Auto-incrément (1, 2, 3...)
    nom VARCHAR(100) NOT NULL,         -- Chaîne avec limite
    bio TEXT,                          -- Chaîne sans limite stricte
    age INT CHECK (age >= 18),         -- Entier avec contrainte
    salaire DECIMAL(10,2),             -- Décimal précis (10 chiffres total, 2 après virgule)
    is_active BOOLEAN DEFAULT TRUE,    -- Converti en TINYINT(1) sous le capot (1 ou 0)
    date_embauche TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB; -- Moteur recommandé supportant les transactions et clés étrangères

4. Clés Étrangères (Relations)

Lier deux tables ensemble et définir le comportement en cas de suppression.

CREATE TABLE departements (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom VARCHAR(50)
);

CREATE TABLE employes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom VARCHAR(100),
    departement_id INT,
    FOREIGN KEY (departement_id) REFERENCES departements(id) ON DELETE CASCADE
);
-- ON DELETE CASCADE : Si on supprime un département, 
-- tous ses employés sont supprimés automatiquement.

5. Opérations CRUD (Manipulation des données)

Insertion (CREATE)

INSERT INTO employes (nom, age, salaire) 
VALUES ('Alice', 30, 2500.50),
       ('Bob', 25, 2100.00);

-- Récupérer le dernier ID inséré dans cette session :
SELECT LAST_INSERT_ID();

Lecture (READ)

SELECT nom, salaire FROM employes 
WHERE age >= 25 
ORDER BY salaire DESC 
LIMIT 5, 10; -- Pagination: sauter 5, en prendre 10

Mise à jour (UPDATE)

UPDATE employes 
SET salaire = salaire + 100, is_active = TRUE 
WHERE nom = 'Bob';

Suppression (DELETE)

DELETE FROM employes WHERE is_active = FALSE;

6. Modifier une structure existante (ALTER TABLE)

-- Ajouter une colonne
ALTER TABLE employes ADD COLUMN email VARCHAR(150);

-- Renommer une colonne
ALTER TABLE employes CHANGE nom nom_complet VARCHAR(150);

-- Modifier le type d'une colonne
ALTER TABLE employes MODIFY salaire DECIMAL(12,2);

-- Supprimer une colonne
ALTER TABLE employes DROP COLUMN bio;

7. Gestion des Utilisateurs et Droits (Sécurité)

Créer et modifier des utilisateurs

-- Créer un utilisateur pouvant se connecter depuis n'importe où (%)
CREATE USER 'dev'@'%' IDENTIFIED BY 'secret123';

-- Créer un rôle de groupe (MySQL 8.0+)
CREATE ROLE 'lecteurs';

-- Assigner le rôle à l'utilisateur
GRANT 'lecteurs' TO 'dev'@'%';
-- L'utilisateur devra exécuter "SET ROLE lecteurs;" après s'être connecté.
-- Ou l'activer par défaut : SET DEFAULT ROLE 'lecteurs' TO 'dev'@'%';

Gérer les permissions (GRANT / REVOKE)

-- Donner tous les droits sur une base (attention)
GRANT ALL PRIVILEGES ON e_commerce.* TO 'dev'@'%';

-- Donner le droit de lecture via un rôle
GRANT SELECT ON e_commerce.* TO 'lecteurs';

-- Donner des droits spécifiques sur une table précise
GRANT INSERT, UPDATE ON e_commerce.employes TO 'dev'@'%';

-- Appliquer les changements (souvent nécessaire après modification manuelle des tables système)
FLUSH PRIVILEGES;

-- Retirer (révoquer) un droit
REVOKE UPDATE ON e_commerce.employes FROM 'dev'@'%';
