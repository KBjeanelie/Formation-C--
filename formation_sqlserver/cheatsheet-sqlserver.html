Guide de Survie

Cheatsheet T-SQL

Un aide-mémoire complet pour maîtriser le dialecte T-SQL de SQL Server, de zéro à expert.

1. Structure d'une base et navigation

-- Créer une base de données
CREATE DATABASE e_commerce;
GO

-- Se connecter à cette base (équivalent de USE en MySQL)
USE e_commerce;
GO

-- Lister les tables de la base actuelle
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE = 'BASE TABLE';

-- Voir la structure d'une table
EXEC sp_help 'employes';

2. Création de Tables & Types T-SQL

SQL Server utilise IDENTITY pour l'auto-incrémentation et des types de données propres.

CREATE TABLE employes (
    id INT IDENTITY(1,1) PRIMARY KEY, -- Auto-incrément (début=1, pas=1)
    nom NVARCHAR(100) NOT NULL,       -- Unicode (accents, emojis supportés)
    bio NVARCHAR(MAX),                -- Texte sans limite de longueur
    age INT CHECK (age >= 18),
    salaire DECIMAL(10,2),
    is_active BIT DEFAULT 1,          -- Booléen : 1 = TRUE, 0 = FALSE
    date_embauche DATETIME2 DEFAULT GETDATE()  -- Date/heure précise
);

3. Clés Étrangères

CREATE TABLE departements (
    id INT IDENTITY(1,1) PRIMARY KEY,
    nom NVARCHAR(50)
);

CREATE TABLE employes (
    id INT IDENTITY(1,1) PRIMARY KEY,
    nom NVARCHAR(100),
    departement_id INT FOREIGN KEY REFERENCES departements(id) ON DELETE CASCADE
);

4. Opérations CRUD

Insertion avec récupération de l'ID

INSERT INTO employes (nom, age, salaire) VALUES ('Alice', 30, 2500.50);

-- Récupérer l'ID inséré dans la même transaction :
SELECT SCOPE_IDENTITY() AS dernier_id;

Lecture avec pagination (OFFSET-FETCH)

SELECT nom, salaire FROM employes
ORDER BY salaire DESC
OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY; -- équivalent de LIMIT 10 OFFSET 5

Update et Delete

UPDATE employes SET salaire = salaire + 100 WHERE nom = 'Bob';
DELETE FROM employes WHERE is_active = 0;

5. Modifier une structure existante

-- Ajouter une colonne
ALTER TABLE employes ADD email NVARCHAR(150);

-- Modifier le type d'une colonne
ALTER TABLE employes ALTER COLUMN salaire DECIMAL(12,2);

-- Renommer une colonne (avec la procédure système)
EXEC sp_rename 'employes.nom', 'nom_complet', 'COLUMN';

-- Supprimer une colonne
ALTER TABLE employes DROP COLUMN bio;

6. Gestion des Utilisateurs et Droits

SQL Server distingue deux niveaux : le Login (connexion au serveur) et le User (accès à une base de données spécifique).

-- 1. Créer un login au niveau du serveur
CREATE LOGIN app_dev WITH PASSWORD = 'SecretPwd!1';

-- 2. Créer un user dans la base de données, lié au login
USE e_commerce;
CREATE USER app_dev FOR LOGIN app_dev;

-- 3. Assigner un rôle de base de données (db_datareader = lecture seule)
ALTER ROLE db_datareader ADD MEMBER app_dev;
-- Autres rôles intégrés : db_datawriter (écriture), db_owner (tout)

-- 4. GRANT / REVOKE granulaire
GRANT SELECT ON employes TO app_dev;
GRANT EXECUTE ON PROCEDURE effectuer_virement TO app_dev;
REVOKE UPDATE ON employes FROM app_dev;

7. Jointures de base

SELECT e.nom, d.nom AS departement
FROM employes e
INNER JOIN departements d ON e.departement_id = d.id;
-- LEFT JOIN, RIGHT JOIN fonctionnent de la même façon
