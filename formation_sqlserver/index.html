Bases de Données (SQL Server L3)

Formation axée 100% TP sur le T-SQL, les transactions TRY...CATCH, l'optimisation avec les plans d'exécution et l'introduction au NoSQL.

Prérequis

Installation SQL Server

Configurez SQL Server Developer Edition et SSMS/Azure Data Studio sur Windows, macOS ou Linux.

 Guide / Doc

Cheatsheet T-SQL

Rappels : IDENTITY, GO, types de données, commandes de survie et gestion des utilisateurs et connexions.

T-SQL : Procédures & Triggers

Programmation serveur en T-SQL. Procédures stockées, fonctions scalaires et triggers Statement-Level avec les tables virtuelles inserted et deleted.

Transactions & Sécurité

Gestion robuste des erreurs avec TRY...CATCH, XACT_ABORT, et système de sécurité avec Logins, Users et Rôles.

 Séance 3 (4h)

Plans d'exécution & Index

Analysez les plans d'exécution graphiques (SSMS) et textuels (SET STATISTICS). Différence Clustered vs Non-Clustered Index.

 Séance 4 (4h)

Bascule vers le NoSQL

Introduction à MongoDB. Stockage orienté document (JSON), requêtes CRUD et pipeline d'agrégation.
