Recueil d'Exercices : PostgreSQL Avancé

Blocs Anonymes, Fonctions PL/pgSQL et Triggers (Séances 1 & 2)

Niveau Facile : Les bases de PL/pgSQL

Exercice 1 : Premier Bloc Anonyme

Écrivez un bloc anonyme (DO $$ ...) qui déclare une variable nom de type VARCHAR avec la valeur de votre choix, puis affiche un message dans la console : "Bonjour [votre nom] !".

Indice : Utilisez l'instruction RAISE NOTICE pour afficher du texte, et le symbole % pour concaténer une variable.

Exercice 2 : Structure Conditionnelle (IF/ELSE)

Créez un bloc anonyme avec une variable note (entier). Si la note est supérieure ou égale à 10, affichez "Validé". Sinon, affichez "Non validé".

Indice : La structure de base est IF condition THEN ... ELSE ... END IF;

Exercice 3 : La Boucle FOR

Écrivez un bloc anonyme qui utilise une boucle pour afficher la table de multiplication par 7 (de 1 à 10).

Indice : Utilisez FOR i IN 1..10 LOOP ... END LOOP;.

Exercice 4 : Ma première Fonction

Créez une fonction nommée multiplier qui prend deux paramètres entiers et retourne leur produit. Testez-la avec un SELECT.

Indice : La fonction doit être définie avec RETURNS INT. N'oubliez pas le bloc BEGIN ... END; et l'instruction RETURN.

Exercice 5 : Fonction texte simple

Créez une fonction saluer(nom VARCHAR) qui retourne la chaîne de caractères "Bonjour, " suivie du nom. Si le nom est NULL, elle doit retourner "Bonjour, inconnu".

Indice : Vous pouvez utiliser l'opérateur de concaténation || ou la fonction COALESCE().

Niveau Intermédiaire : Manipulation de données et Triggers simples

Pour ces exercices, imaginez une table produits(id SERIAL PRIMARY KEY, nom VARCHAR, prix DECIMAL, stock INT).

Exercice 6 : Formatage avant insertion (Trigger)

Créez une fonction trigger et un trigger (BEFORE INSERT sur la table produits) qui met systématiquement le nom du produit en MAJUSCULES avant de l'enregistrer dans la base.

Indice : Dans la fonction trigger, modifiez la variable spéciale NEW.nom avec la fonction SQL UPPER(), puis retournez NEW.

Exercice 7 : Validation des données (RAISE EXCEPTION)

Créez un trigger BEFORE INSERT OR UPDATE qui empêche d'enregistrer un produit si son prix est négatif ou nul. L'erreur doit afficher le message : "Le prix doit être strictement positif".

Indice : Utilisez IF NEW.prix <= 0 THEN RAISE EXCEPTION '...'; END IF;

Exercice 8 : Boucle sur un résultat de requête (Record)

Écrivez un bloc anonyme qui parcourt tous les produits dont le stock est inférieur à 10, et affiche pour chacun d'eux : "Alerte stock : [nom du produit] (Reste: [stock])".

Indice : Déclarez une variable de type RECORD et utilisez FOR ma_variable IN (SELECT ...) LOOP ...

Exercice 9 : Fonction retournant plusieurs valeurs

Créez une fonction get_produits_chers(seuil DECIMAL) qui retourne le nom et le prix de tous les produits dont le prix est supérieur au seuil passé en paramètre.

Indice : Utilisez RETURNS TABLE (nom VARCHAR, prix DECIMAL) et RETURN QUERY SELECT ...

Exercice 10 : Journalisation des suppressions (Audit)

Créez une table audit_produits(nom VARCHAR, date_suppression TIMESTAMP). Puis, créez un trigger AFTER DELETE sur produits qui insère automatiquement le nom du produit supprimé dans la table d'audit.

Indice : Lors d'un DELETE, les anciennes valeurs sont accessibles via la variable spéciale OLD. N'oubliez pas de retourner OLD à la fin.

Niveau Difficile : Cas concrets et logiques avancées

Pour ces exercices, imaginez une table comptes(id SERIAL PRIMARY KEY, titulaire VARCHAR, solde DECIMAL) et une table historique(id SERIAL, msg TEXT).

Exercice 11 : Gestion des exceptions (Try/Catch)

Écrivez un bloc anonyme qui tente de diviser 10 par 0, et qui "attrape" l'erreur avec un bloc EXCEPTION pour afficher proprement : "Erreur mathématique détectée !", sans faire planter la requête.

Indice : En PL/pgSQL, utilisez la section EXCEPTION WHEN division_by_zero THEN ... avant le END final.

Exercice 12 : Fonction de Virement Transactionnel

Créez une fonction virement(compte_source INT, compte_dest INT, montant DECIMAL) qui déduit l'argent du compte source et l'ajoute au compte de destination. Si le compte source n'a pas assez d'argent, levez une exception.

Indice : Récupérez d'abord le solde source avec SELECT INTO. Si c'est insuffisant, utilisez RAISE EXCEPTION. Sinon, faites les deux UPDATE consécutifs.

Exercice 13 : Empêcher la modification de données sensibles

Créez un trigger BEFORE UPDATE sur comptes qui interdit formellement de modifier le nom du titulaire. Seul le solde peut être mis à jour. (Message d'erreur : "Changement de propriétaire interdit").

Indice : Comparez NEW.titulaire avec OLD.titulaire (utilisez IS DISTINCT FROM pour gérer les cas NULL proprement).

Exercice 14 : Maintien d'un total (Denormalisation)

Imaginez une table unique statistiques(total_fonds DECIMAL) contenant une seule ligne. Créez un trigger qui met à jour ce grand total automatiquement à chaque INSERT, UPDATE ou DELETE sur la table comptes.

Indice : Vous devrez gérer les opérations spéciales TG_OP = 'INSERT', 'UPDATE', et 'DELETE' dans un IF/ELSIF, et ajuster le total_fonds en utilisant NEW.solde et/ou OLD.solde.

Exercice 15 : SQL Dynamique avec EXECUTE

Créez une fonction compter_lignes(nom_table VARCHAR) qui retourne le nombre total de lignes d'une table dont le nom est passé en paramètre. (Attention: Impossible de faire un SELECT COUNT directement avec une variable comme nom de table, il faut du SQL dynamique).

Indice : Utilisez l'instruction EXECUTE 'SELECT COUNT(*) FROM ' || quote_ident(nom_table) INTO variable_resultat;
