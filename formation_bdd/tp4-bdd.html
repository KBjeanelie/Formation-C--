Séance 4

Introduction au NoSQL (MongoDB)

Oubliez les tables et les jointures. Stockons nos données sous forme de documents JSON ultra-flexibles !

Prérequis & Installation

1. Installez MongoDB Community Edition depuis mongodb.com.

2. Installez le client graphique MongoDB Compass pour visualiser vos collections facilement.

3. Ouvrez un terminal (mongosh) pour exécuter les commandes suivantes.

TP 1 : Création et Insertion (CRUD)

Objectif : Sélectionner une base blog (qui se créera toute seule). Insérer un article avec des tags et des commentaires imbriqués (ce qui nécessiterait 3 tables en SQL).
Voir la solution 
use blog

db.articles.insertOne({
    titre: "Découvrir MongoDB",
    auteur: "Walter",
    tags: ["NoSQL", "Base de données", "JSON"],
    commentaires: [
        { user: "Alice", texte: "Super article !", like: 5 },
        { user: "Bob", texte: "Très clair.", like: 2 }
    ]
})

-- Pour vérifier :
db.articles.find().pretty()

TP 2 : La Recherche Avancée

Objectif : Trouver tous les articles qui possèdent le tag "NoSQL" et dont le nom de l'auteur est "Walter".
Voir la solution 
db.articles.find({ 
    tags: "NoSQL", 
    auteur: "Walter" 
})

TP 3 : Mise à jour dans un Document

Objectif : Ajouter un nouveau tag "Tutoriel" au tableau de tags de l'article précédent, sans écraser les existants.
Voir la solution 
db.articles.updateOne(
    { titre: "Découvrir MongoDB" },
    { $push: { tags: "Tutoriel" } }
)
