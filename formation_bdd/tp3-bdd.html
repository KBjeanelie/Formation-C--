Séance 3

Crash Test & Indexation

Comment une base de données gère-t-elle des millions de lignes ? Découvrez le pouvoir des index B-Tree et la lecture des plans d'exécution.

Introduction (Théorie - 15 min)

Sans index, pour trouver une ligne, la base doit lire TOUTE la table (Seq Scan / Full Table Scan). Un Index (B-Tree) agit comme l'index à la fin d'un livre : il pointe directement vers la bonne page (Index Scan).

Pour auditer une requête lente, on ajoute EXPLAIN ANALYZE avant le SELECT.

TP 1 : Génération du Million de lignes

Objectif : Créer une table logs et la remplir avec 2 millions de fausses requêtes HTTP à l'aide de generate_series.
Voir la solution 
CREATE TABLE logs (
    id SERIAL PRIMARY KEY,
    ip_address VARCHAR(15),
    status_code INT,
    created_at TIMESTAMP
);

-- Insertion de 2 millions de lignes aléatoires (Prend quelques secondes)
INSERT INTO logs (ip_address, status_code, created_at)
SELECT 
    '192.168.1.' || (random() * 255)::int,
    (ARRAY[200, 404, 500])[ceil(random()*3)],
    NOW() - (random() * interval '365 days')
FROM generate_series(1, 2000000);

TP 2 : Analyse et Constat (Le Seq Scan)

Objectif : Compter combien de requêtes proviennent de l'IP "192.168.1.50". Analyser la performance de cette requête.
Voir la solution 
EXPLAIN ANALYZE 
SELECT COUNT(*) FROM logs WHERE ip_address = '192.168.1.50';

Observez le résultat : Le moteur indique un Seq Scan on logs. Le temps d'exécution (Execution Time) sera probablement supérieur à 100ms ou 200ms, ce qui est énorme pour une simple recherche web.

TP 3 : La Magie de l'Index

Objectif : Créer un index sur la colonne ip_address et relancer l'analyse.
Voir la solution 
-- Création de l'index (Prend un peu de temps car il doit trier 2M de lignes)
CREATE INDEX idx_logs_ip ON logs(ip_address);

-- Relançons l'analyse :
EXPLAIN ANALYZE 
SELECT COUNT(*) FROM logs WHERE ip_address = '192.168.1.50';

Le résultat indique maintenant un Bitmap Index Scan ou Index Only Scan. Le temps d'exécution devrait s'effondrer autour de 1ms ! L'optimisation a été multipliée par 100.
