Projet Final

GED : Gestion Électronique de Documents

Ce guide va vous accompagner pas à pas pour créer un système complet d'archivage sécurisé (upload de fichiers PDF/Images, catégorisation, droits d'accès et déploiement).

🎯 Objectif de l'application : Permettre aux utilisateurs authentifiés d'ajouter des documents, de les classer par catégorie, et de les télécharger de manière sécurisée.
Étape 1

Installation & Authentification

Nous allons partir sur une base saine avec le scaffolding d'authentification Laravel Breeze.

composer create-project laravel/laravel archivage-app
cd archivage-app
composer require laravel/breeze --dev
php artisan breeze:install blade
npm install && npm run build
php artisan migrate
Étape 2

Modélisation de la Base de Données

Nous avons besoin de 2 entités : Category et Document.

1. Les Catégories

php artisan make:model Category -m

Dans la migration create_categories_table :

Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->timestamps();
});

2. Les Documents

php artisan make:model Document -m

Dans la migration create_documents_table :

Schema::create('documents', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->string('file_path'); // Stockera le chemin du fichier
    $table->foreignId('category_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->timestamps();
});

Appliquez les migrations avec : php artisan migrate.

Étape 3

L'Upload de Fichiers (Le Cœur du Projet)

Laravel utilise un système de disques (local, public, s3). Par défaut, les fichiers uploadés dans storage/app/public ne sont pas accessibles depuis le web. Il faut créer un lien symbolique :

php artisan storage:link

Le Contrôleur de Document

php artisan make:controller DocumentController

Dans DocumentController.php (Méthode Store) :

use Illuminate\Support\Facades\Storage;

public function store(Request $request)
{
    $request->validate([
        'title' => 'required|string|max:255',
        'category_id' => 'required|exists:categories,id',
        'file' => 'required|file|mimes:pdf,jpg,png,doc,docx|max:10240', // Max 10MB
    ]);

    // L'upload magique
    $path = $request->file('file')->store('documents', 'public');

    Document::create([
        'title' => $request->title,
        'file_path' => $path,
        'category_id' => $request->category_id,
        'user_id' => auth()->id(),
    ]);

    return redirect()->route('dashboard')->with('success', 'Document archivé avec succès !');
}
Étape 4

Le Téléchargement Sécurisé

Plutôt que de donner un lien direct au fichier, il est plus sûr de forcer le téléchargement via un contrôleur (ce qui permet d'ajouter des vérifications de droits avec les Policies).

public function download(Document $document)
{
    // On vérifie que le fichier existe bien sur le disque
    if (Storage::disk('public')->exists($document->file_path)) {
        return Storage::disk('public')->download($document->file_path, $document->title);
    }
    
    abort(404, "Fichier introuvable.");
}
Étape 5

Les Vues (Formulaire HTML)

Dans votre formulaire d'upload (Blade), il est crucial de ne pas oublier l'attribut enctype="multipart/form-data", sinon le fichier ne sera pas envoyé au serveur.

<form action="{{ route('documents.store') }}" method="POST" enctype="multipart/form-data">
    @csrf
    
    <label>Titre du document</label>
    <input type="text" name="title" required>

    <label>Fichier (PDF, Images, Word)</label>
    <input type="file" name="file" required>

    <button type="submit">Archiver</button>
</form>
Étape 6

Conseils de Déploiement (Production)

Déployer une application Laravel demande quelques étapes cruciales pour garantir la sécurité et la performance de votre système d'archivage.

  1. Fichier .env : Passez APP_ENV=production et APP_DEBUG=false. Cela évitera d'afficher des erreurs détaillées avec vos mots de passe de base de données à vos utilisateurs.
  2. Optimisation des performances : Exécutez ces commandes pour mettre en cache la configuration et les routes : 
    php artisan config:cache
php artisan route:cache
php artisan view:cache
  3. Le Lien Symbolique : Sur le serveur de production, n'oubliez pas de relancer la commande pour rendre les fichiers téléchargeables : php artisan storage:link.
  4. Droits des dossiers (Linux) : Les dossiers storage et bootstrap/cache doivent être inscriptibles par le serveur web (souvent www-data). 
    sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache
  5. Uploads volumineux (PHP.ini) : Si vos utilisateurs archivent de gros PDF, modifiez le php.ini de votre serveur de production pour augmenter les limites : 
    upload_max_filesize = 50M
post_max_size = 50M
