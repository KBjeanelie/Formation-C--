Environnement Laravel avec Docker

La solution ultime pour uniformiser le développement. Peu importe que vous soyez sous Windows, macOS ou Linux, l'environnement fonctionnera de la même manière.

Pourquoi Docker ?
Docker permet d'encapsuler votre application (PHP, Nginx, MySQL, Redis) dans des "conteneurs". Plus de problème de version PHP différente entre les développeurs ou de conflits de bases de données (le fameux "Ça marche sur ma machine !").

L'approche officielle : Laravel Sail

La manière la plus simple recommandée par Laravel est d'utiliser Sail, qui est une interface en ligne de commande intégrée pour interagir avec l'environnement Docker par défaut de Laravel.

Installation sur un nouveau projet

Sur n'importe quel système avec Docker installé, lancez simplement :

curl -s https://laravel.build/mon-projet | bash
cd mon-projet
./vendor/bin/sail up

Installation sur un projet existant

composer require laravel/sail --dev
php artisan sail:install
./vendor/bin/sail up

L'approche manuelle (Pour comprendre comment ça marche)

Parfois, on souhaite maîtriser entièrement son infrastructure sans utiliser Sail. Voici comment configurer manuellement un environnement Nginx + PHP-FPM + MySQL avec docker-compose.

1. Fichier docker-compose.yml (À la racine du projet)

version: '3.8'

services:
  app:
    build:
      context: .
      dockerfile: Dockerfile
    image: laravel-app
    container_name: laravel_app
    restart: unless-stopped
    working_dir: /var/www/html
    volumes:
      - ./:/var/www/html
    depends_on:
      - db

  nginx:
    image: nginx:alpine
    container_name: laravel_nginx
    restart: unless-stopped
    ports:
      - "8000:80"
    volumes:
      - ./:/var/www/html
      - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - app

  db:
    image: mysql:8.0
    container_name: laravel_db
    restart: unless-stopped
    environment:
      MYSQL_DATABASE: ${DB_DATABASE}
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_PASSWORD: ${DB_PASSWORD}
      MYSQL_USER: ${DB_USERNAME}
    ports:
      - "3306:3306"
    volumes:
      - dbdata:/var/lib/mysql

volumes:
  dbdata:

2. Le Dockerfile pour le service PHP

Créez un fichier Dockerfile à la racine :

FROM php:8.2-fpm

# Installation des dépendances système
RUN apt-get update && apt-get install -y \
    git \
    curl \
    libpng-dev \
    libonig-dev \
    libxml2-dev \
    zip \
    unzip

# Installation des extensions PHP requises par Laravel
RUN docker-php-ext-install pdo_mysql mbstring exif pcntl bcmath gd

# Récupération de Composer
COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

WORKDIR /var/www/html

3. Configuration Nginx

Créez le fichier docker/nginx/default.conf :

server {
    listen 80;
    index index.php index.html;
    server_name localhost;
    error_log  /var/log/nginx/error.log;
    access_log /var/log/nginx/access.log;
    root /var/www/html/public;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        try_files $uri =404;
        fastcgi_split_path_info ^(.+\.php)(/.+)$;
        fastcgi_pass app:9000;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_param PATH_INFO $fastcgi_path_info;
    }
}

Démarrage et Utilisation

  1. Assurez-vous que Docker Desktop (ou le démon Docker) est lancé sur votre machine.
  2. Copiez votre .env.example en .env et ajustez les variables DB pour matcher le docker-compose (DB_HOST=db).
  3. Construisez et démarrez les conteneurs : docker-compose up -d --build
  4. Entrez dans le conteneur PHP pour installer les vendors : docker-compose exec app composer install
  5. Générez la clé de l'application : docker-compose exec app php artisan key:generate
  6. Jouez les migrations : docker-compose exec app php artisan migrate
  7. Votre site est disponible sur http://localhost:8000.
