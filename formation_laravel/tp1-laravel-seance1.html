Bases, Architecture MVC et Routage

Le principe du MVC

Laravel repose sur l'architecture Modèle-Vue-Contrôleur (MVC) :

  • Modèle (M) : Gère les données et la logique métier (Base de données).
  • Vue (V) : Ce qui est affiché à l'utilisateur (HTML, CSS).
  • Contrôleur (C) : Fait le lien entre le Modèle et la Vue. Il reçoit la requête, demande des données au Modèle, et les passe à la Vue.

Le Routage (Routing)

Toutes les requêtes passent par le fichier routes/web.php. Voici comment déclarer une route simple :

Route::get('/bonjour', function () {
    return 'Bonjour le monde !';
});
