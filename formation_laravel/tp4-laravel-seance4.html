Formulaires et Validation

Protection CSRF

Laravel protège automatiquement votre application contre les attaques CSRF (Cross-Site Request Forgery). Tout formulaire POST, PUT, PATCH ou DELETE doit inclure le jeton CSRF via la directive @csrf.

<form method="POST" action="/profile">
    @csrf
    <input type="text" name="name">
    <button type="submit">Envoyer</button>
</form>

Validation des données

Dans votre contrôleur, vous pouvez valider les données entrantes avec la méthode validate fournie par l'objet Request.

public function store(Request $request)
{
    $validated = $request->validate([
        'title' => 'required|unique:posts|max:255',
        'body' => 'required',
    ]);

    // Le code suivant ne s'exécute que si la validation réussit
    // Si elle échoue, Laravel redirige automatiquement l'utilisateur en arrière avec les erreurs
}

Afficher les erreurs dans la vue Blade :

@error('title')
    <div class="alert alert-danger">{{ $message }}</div>
@enderror
