10 Mini-TPs Laravel

Entraînez-vous avec ces 10 petits exercices couvrant les notions fondamentales du framework. Les solutions sont cachées, cherchez d'abord par vous-même !

01

La Route et la Vue (Hello World)

Objectif : Créer une route accessible sur /hello qui retourne une vue simple affichant "Bienvenue sur Laravel".
Voir la solution

1. Dans routes/web.php :

Route::get('/hello', function () {
    return view('hello');
});

2. Créer un fichier resources/views/hello.blade.php :

<h1>Bienvenue sur Laravel</h1>
02

Contrôleur et Paramètres

Objectif : Créer une route dynamique /user/{name} liée à une méthode de contrôleur qui renvoie le nom en majuscule.
Voir la solution

1. Générer le contrôleur :

php artisan make:controller UserController

2. Dans UserController.php :

public function show($name) {
    return "Bonjour " . strtoupper($name);
}

3. Dans routes/web.php :

use App\Http\Controllers\UserController;
Route::get('/user/{name}', [UserController::class, 'show']);
03

Migration et Modèle

Objectif : Créer une table tasks (id, title, is_completed) et son modèle Eloquent associé en une seule commande artisan.
Voir la solution

1. La commande artisan (le -m génère la migration) :

php artisan make:model Task -m

2. Dans le fichier de migration (database/migrations/xxxx_create_tasks_table.php) :

public function up() {
    Schema::create('tasks', function (Blueprint $table) {
        $table->id();
        $table->string('title');
        $table->boolean('is_completed')->default(false);
        $table->timestamps();
    });
}
04

Validation de Formulaire

Objectif : Valider une requête POST pour créer une tâche (le titre est obligatoire et doit faire au moins 3 caractères).
Voir la solution

Dans un contrôleur TaskController :

public function store(Request $request) {
    $validated = $request->validate([
        'title' => 'required|min:3',
    ]);

    Task::create($validated);
    
    return redirect()->back()->with('success', 'Tâche ajoutée');
}
05

Eloquent ORM : Filtres

Objectif : Récupérer uniquement les tâches qui ne sont pas terminées (is_completed = false), triées par date de création décroissante.
Voir la solution 
$tasks = Task::where('is_completed', false)
             ->orderBy('created_at', 'desc')
             ->get();
06

Relations Eloquent (1-N)

Objectif : Lier un User à plusieurs Post. Définir la méthode de relation dans le modèle User.
Voir la solution

Dans app/Models/User.php :

public function posts() {
    return $this->hasMany(Post::class);
}

Pour récupérer les posts de l'utilisateur n°1 :

$user = User::find(1);
$mesPosts = $user->posts; // Notez l'absence de ()
07

Middleware (Filtre HTTP)

Objectif : Créer un Middleware CheckAge qui redirige vers l'accueil si l'âge passé en paramètre de requête est inférieur à 18.
Voir la solution

1. Génération :

php artisan make:middleware CheckAge

2. Dans CheckAge.php :

public function handle(Request $request, Closure $next) {
    if ($request->age < 18) {
        return redirect('/');
    }
    return $next($request);
}
08

Moteur de template Blade

Objectif : Faire une boucle @foreach dans une vue Blade pour afficher une liste de tâches, et afficher "Aucune tâche" si le tableau est vide.
Voir la solution 
<ul>
@forelse($tasks as $task)
    <li>{{ $task->title }}</li>
@empty
    <li>Aucune tâche pour le moment.</li>
@endforelse
</ul>
09

Seeder et Factory

Objectif : Créer 50 utilisateurs fictifs dans la base de données via une commande artisan.
Voir la solution

Dans database/seeders/DatabaseSeeder.php :

public function run() {
    \App\Models\User::factory(50)->create();
}

Lancement :

php artisan db:seed
10

API et Réponses JSON

Objectif : Renvoyer un message d'erreur JSON avec un code HTTP 404 lorsqu'une ressource n'est pas trouvée manuellement dans un contrôleur.
Voir la solution 
public function show($id) {
    $item = Item::find($id);
    
    if (!$item) {
        return response()->json([
            'error' => 'Ressource introuvable'
        ], 404);
    }
    
    return response()->json($item);
}
