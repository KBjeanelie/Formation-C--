Base de données et Eloquent ORM

Les Migrations

Les migrations sont le contrôle de version de votre base de données. Elles permettent à l'équipe de modifier le schéma de base de données de l'application et de le partager.

php artisan make:migration create_flights_table

Exemple de contenu de la méthode up() :

Schema::create('flights', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('airline');
    $table->timestamps();
});

Pour appliquer les migrations : php artisan migrate

L'ORM Eloquent

Eloquent est un ORM (Object-Relational Mapper) qui rend l'interaction avec la base de données très simple et orientée objet.

Créer un modèle : php artisan make:model Flight

// Récupérer tous les vols
$flights = App\Models\Flight::all();

// Trouver un vol par son ID
$flight = App\Models\Flight::find(1);

// Créer un nouveau vol
$flight = new App\Models\Flight;
$flight->name = 'Paris-Londres';
$flight->save();
