01

Les pointeurs

Un pointeur est une variable qui ne contient pas une donnée directement, mais l'adresse mémoire d'une autre variable.

Deux opérateurs suffisent à comprendre les pointeurs :

&xadresse de la variable x
↔
*pvaleur pointée par p (déréférencement)
int age = 20;
int* p = &age;   // p contient l'adresse de "age"

std::cout << age;   // 20 — la valeur
std::cout << &age;  // une adresse du type 0x7ffee...
std::cout << p;      // la même adresse que &age
std::cout << *p;     // 20 — la valeur pointée par p

*p = 25;              // modifie "age" via le pointeur
std::cout << age;    // 25

Un pointeur peut aussi ne pointer vers rien, avec nullptr :

int* p2 = nullptr;

if (p2 == nullptr) {
    std::cout << "p2 ne pointe vers rien";
}
Piège fréquent : déréférencer un pointeur non initialisé ou nullptr avec *p provoque un plantage (accès mémoire invalide). Toujours s'assurer qu'un pointeur pointe vers une adresse valide avant de le déréférencer.

Un pointeur passé en paramètre de fonction permet, comme une référence, de modifier la variable d'origine :

void doubler(int* p) {
    *p = *p * 2;
}

int main() {
    int n = 5;
    doubler(&n);
    std::cout << n; // 10
}

TPÉchange par pointeurs

facile

Écrire une fonction void echanger(int* a, int* b) qui échange les valeurs pointées par a et b, en utilisant uniquement des pointeurs (pas de référence & en paramètre). Tester avec deux variables dans main.

Voir la solution 
#include <iostream>

void echanger(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 3, y = 9;
    std::cout << "Avant : x=" << x << " y=" << y << std::endl;

    echanger(&x, &y);

    std::cout << "Après : x=" << x << " y=" << y << std::endl;

    return 0;
}

C'est le même résultat que l'échange par référence vu en séance 2 — mais ici on manipule explicitement des adresses avec &x et &y à l'appel, et on déréférence avec *a / *b à l'intérieur de la fonction.

02

Les références

Une référence est un alias : un autre nom pour une variable déjà existante, et non une variable séparée.
int age = 20;
int& ref = age;  // ref est un autre nom pour "age"

ref = 25;
std::cout << age; // 25 — "age" a changé, car ref EST age
PointeurRéférence
Peut être réaffecté à autre choseToujours liée à la même variable, définitivement
Peut valoir nullptrDoit obligatoirement être initialisée à la déclaration
Nécessite * pour lire la valeurSe manipule comme la variable elle-même

En pratique, les références sont surtout utilisées en paramètre de fonction, pour éviter une copie coûteuse ou pour modifier la variable appelante — comme vu en séance 2 avec void doubler(int& x).

Quand choisir quoi : référence par défaut pour les paramètres de fonction ; pointeur seulement si l'on a besoin de "ne pointer vers rien" (nullptr) ou de changer ce qui est pointé en cours de route.

TPStatistiques par référence

intermédiaire

Écrire une fonction void statistiques(int tab[], int taille, int& min, int& max, double& moyenne) qui calcule en une seule passe le minimum, le maximum et la moyenne d'un tableau, en renvoyant les trois résultats par référence.

Voir la solution 
#include <iostream>

void statistiques(int tab[], int taille, int& min, int& max, double& moyenne) {
    min = tab[0];
    max = tab[0];
    int somme = 0;

    for (int i = 0; i < taille; i++) {
        if (tab[i] < min) min = tab[i];
        if (tab[i] > max) max = tab[i];
        somme += tab[i];
    }

    moyenne = (double)somme / taille;
}

int main() {
    int valeurs[6] = {12, 8, 21, 5, 17, 14};
    int min, max;
    double moyenne;

    statistiques(valeurs, 6, min, max, moyenne);

    std::cout << "Min : " << min << std::endl;
    std::cout << "Max : " << max << std::endl;
    std::cout << "Moyenne : " << moyenne << std::endl;

    return 0;
}

Sans références, la fonction ne pourrait retourner qu'une seule valeur avec return — les paramètres par référence permettent de "retourner" plusieurs résultats à la fois.

03

Allocation dynamique

Avec new, on réserve de la mémoire à l'exécution, dont la taille peut dépendre d'une valeur connue seulement au lancement du programme.
int* p = new int;   // réserve un int sur le tas
*p = 42;
std::cout << *p;

delete p;         // libère la mémoire

Pour un tableau, la taille peut être une variable (contrairement à un tableau statique) :

int taille;
std::cout << "Combien de valeurs ? ";
std::cin >> taille;

int* tab = new int[taille];

for (int i = 0; i < taille; i++) {
    tab[i] = i * i;
}

delete[] tab;  // [] obligatoire pour libérer un tableau
Piège fréquent — fuite mémoire : chaque new doit avoir un delete correspondant (delete[] pour un tableau). Oublier de libérer la mémoire réservée avec new est une fuite mémoire : le programme garde la mémoire occupée même après ne plus en avoir besoin.
Pour aller plus loin : en C++ moderne, on préfère souvent std::vector (vu en séance 4) à new/delete manuels, car il gère automatiquement sa mémoire. Cette section reste utile pour comprendre ce qui se passe "sous le capot".

TPTableau dynamique de notes

intermédiaire

Demander à l'utilisateur combien de notes il souhaite saisir, allouer dynamiquement un tableau de cette taille avec new, remplir le tableau, afficher la moyenne, puis libérer la mémoire avec delete[].

Voir la solution 
#include <iostream>

int main() {
    int nombreNotes;
    std::cout << "Combien de notes ? ";
    std::cin >> nombreNotes;

    double* notes = new double[nombreNotes];

    for (int i = 0; i < nombreNotes; i++) {
        std::cout << "Note " << (i + 1) << " : ";
        std::cin >> notes[i];
    }

    double somme = 0;
    for (int i = 0; i < nombreNotes; i++) {
        somme += notes[i];
    }

    std::cout << "Moyenne : " << (somme / nombreNotes) << std::endl;

    delete[] notes;

    return 0;
}
04

Les structures

Une struct regroupe plusieurs données liées sous un seul type, sans forcément avoir de méthodes ni d'encapsulation — plus légère qu'une classe pour de simples "paquets de données".
struct Point {
    double x;
    double y;
};

int main() {
    Point p1;
    p1.x = 3;
    p1.y = 4;

    std::cout << "(" << p1.x << ", " << p1.y << ")";
}

On peut aussi initialiser une structure directement à la déclaration, et créer des tableaux de structures :

struct Eleve {
    std::string nom;
    int age;
};

Eleve e1 = {"Fabrice", 17};
Eleve classe[3] = {
    {"Fabrice", 17},
    {"Diane", 16},
    {"Yann", 18}
};
structclass
Membres public par défautMembres private par défaut
Convient aux simples regroupements de donnéesConvient quand encapsulation et comportements riches sont nécessaires

TPCarnet de contacts

facile

Définir une structure Contact avec nom et telephone (deux std::string). Créer un tableau de 4 contacts initialisés directement, puis les afficher tous avec une boucle.

Voir la solution 
#include <iostream>
#include <string>

struct Contact {
    std::string nom;
    std::string telephone;

int main() {

        {"Awa", "06 111 22 33"},
        {"Brice", "05 222 33 44"},

    }

    return 0;
}
05

La gestion des fichiers

La bibliothèque <fstream> permet de lire et d'écrire dans des fichiers texte depuis un programme C++.

Écrire dans un fichier avec std::ofstream :

#include <fstream>

int main() {
    std::ofstream fichier("notes.txt");

    if (fichier.is_open()) {
        fichier << "Fabrice 14" << std::endl;
        fichier << "Diane 17" << std::endl;
        fichier.close();
    } else {
        std::cout << "Impossible de créer le fichier.";
    }
}

Lire un fichier ligne par ligne avec std::ifstream et std::getline :

#include <fstream>
#include <iostream>
#include <string>

int main() {
    std::ifstream fichier("notes.txt");
    std::string ligne;

    if (fichier.is_open()) {
        while (std::getline(fichier, ligne)) {
            std::cout << ligne << std::endl;
        }
        fichier.close();
    } else {
        std::cout << "Fichier introuvable.";
    }
}
ClasseUsage
std::ofstreamÉcriture (output)
std::ifstreamLecture (input)
is_open()Vérifie que le fichier a bien été ouvert avant de l'utiliser
std::getline(f, s)Lit une ligne entière du fichier f dans la chaîne s
Piège fréquent : ouvrir un ofstream sur un fichier existant l'écrase par défaut. Toujours vérifier is_open() avant de lire ou écrire, et penser à close() une fois terminé.

TPJournal de dépenses

défi

Écrire un programme qui demande à l'utilisateur de saisir des dépenses (description + montant) jusqu'à ce qu'il tape "fin" comme description, en enregistrant chaque ligne dans un fichier depenses.txt au format description montant. Ensuite, relire le fichier ligne par ligne pour afficher son contenu à l'écran et calculer le total dépensé (avec std::stringstream pour séparer la description du montant sur chaque ligne relue).

Voir la solution 
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>

int main() {
    std::ofstream sortie("depenses.txt");
    std::string description;
    double montant;

    if (!sortie.is_open()) {
        std::cout << "Impossible de créer le fichier.";
        return 1;
    }

    while (true) {
        std::cout << "Description (ou 'fin') : ";
        std::cin >> description;
        if (description == "fin") {
            break;
        }
        std::cout << "Montant : ";
        std::cin >> montant;

        sortie << description << " " << montant << std::endl;
    }
    sortie.close();

    // relecture
    std::ifstream entree("depenses.txt");
    std::string ligne;
    double total = 0;

    std::cout << std::endl << "--- Journal ---" << std::endl;
    while (std::getline(entree, ligne)) {
        std::stringstream ss(ligne);
        std::string desc;
        double m;
        ss >> desc >> m;

        std::cout << desc << " : " << m << " FCFA" << std::endl;
        total += m;
    }
    entree.close();

    std::cout << "Total dépensé : " << total << " FCFA" << std::endl;

    return 0;
}

std::stringstream permet de traiter une chaîne comme un flux, exactement comme std::cin — pratique pour extraire plusieurs valeurs d'une même ligne lue dans un fichier.
